# NEO-Cine（技能说明中文版）

*本文是 [SKILL.md](SKILL.md) 的中文版，给人看的；代理读的是英文版，以英文版为准。*

**这个技能做什么**：在 NEO-Cine 风格库的某一种风格里，导演并制作一支完全用代码做出来的短片。目前有一种风格：折叠城市（Folding City），平面海报式的城市在立面和纵深之间来回折叠。

**什么时候触发**：

- 用户要一支视频、短片、宣传片或动画，指定了 NEO-Cine 的风格，或者提到 NEO-Cine、折叠城市；
- 用户要给自己的题目做片子，还没选风格（帮他选）；
- 用户想把一种风格改成自己的、从空白开始做自己的风格，或者用他存过的风格；
- 用户启动了技能但没说要什么，或者问有哪些风格。

不用于剪辑、裁切、转码用户已有的视频文件。

## 步骤

风格、指南和工具都在 NEO-Cine 库里（github.com/neohoy/neo-cine）。技能只负责把库取下来，然后把工作交给库里的指南。

1. **取库。** 运行 `sh "<技能目录>/scripts/setup.sh"`。它会克隆或更新库（默认在 `~/neo-cine`；如果用户正站在一个克隆里，就直接用那个），最后一行打印 `LIB=<路径>`。
2. **尽早装核心工具。** 马上运行 `sh "<技能目录>/scripts/setup.sh" deps`，能放后台就放后台：第一次要几分钟。`deps voice`、`deps music` 等片子用得上时再装（见 `$LIB/TECHNIQUE.md` §1）。缺少的系统工具（Node、ffmpeg、Python）在那一轮提问里告诉用户，不要自己装系统软件。某个风格需要的包（它的 `STYLE.md` 里列着）由代理装进工程目录。
3. **照库里的指南做。** 读 `$LIB/AGENTS.md`，从 **Start** 开始：先看用户在 `~/neo-my-styles/` 里有没有自己的风格；用户什么都没写就启动技能时，先问语言，再给几种开始方式。之后是选风格或做自己的风格、一轮提问、方案、制作、交付。

## 技能模式下的不同

| | |
|---|---|
| 工程目录 | 用户启动时所在目录下的 `<name>/`（小写字母、数字、连字符；路径里避免 `#` 和 `?`）。指南里写 `films/<name>/` 的地方都指这个目录 |
| 运行工具 | 在 `$LIB` 里运行，传工程的绝对路径：`cd "$LIB" && node core/render/still.mjs "<工程>" 1.5 3` |
| 页面里引用库文件 | 用绝对地址：`/core/lib.js`、`/node_modules/three/…`（工程被挂在 `/@film/` 下） |
| 脚本和 `build.sh` 里引用库文件 | 用 `$LIB/…`，`build.sh` 开头写 `LIB=<路径>`；不要用 `../..` |
| 示范片源码 | 默认不下载。写完自己的 `TREATMENT.md` 之后，才用 `sh "<技能目录>/scripts/setup.sh" demo <slug>` 取下来学手法；它不是拿来直接渲染的 |

按 `$LIB/DIRECTOR.md` §11 列的清单交付到工程目录，并告诉用户文件在哪。每个交付物都带版本号（`-v001`、`-v002`……），不覆盖旧版。

指南的主文件是英文，旁边都有一份中文版（`X.zh-CN.md`）给人看。代理按英文版执行。
