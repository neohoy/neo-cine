# neo/: NEO's own tools

*中文版：[README.zh-CN.md](README.zh-CN.md)*

`core/` is an unmodified mirror of Lemo-Opuscar's tools and is never edited here (see [UPSTREAM.md](../UPSTREAM.md)). Tools that NEO-Cine adds go in this folder, so a sync with upstream can never overwrite them.

- `publish.sh`: uploads the demo films and their 720p web cuts to the repository's releases, for the gallery ([MAINTAINING.md](../MAINTAINING.md), "Publish").
- `geo/osm.py`: turns OpenStreetMap into one JSON file a film page can draw (coast closed into land, water, woods, peaks, roads, railways, buildings, place names; metres around an origin, lines simplified). The styles in the Real Maps series use it; usage is at the top of the file and in [`styles/atlas-scroll/STYLE.md`](../styles/atlas-scroll/STYLE.md) §9 and §10. Data © OpenStreetMap contributors, ODbL 1.0.
- `geo/ohm.py`: the same for OpenHistoricalMap, with dates: borders, railways and named routes, each with the first and last year it existed, so a page can draw the map of any year. Give it the same `--origin` and `--proj` as the `osm.py` file it is drawn over. Used by [`styles/atlas-scroll`](../styles/atlas-scroll/STYLE.md). Data CC0.
- `audio/master.py`: the last step of a film's `mix.py`. It brings the mix to −14 LUFS with one gain for the whole film and shortens only the peaks (a soft clip, then a true-peak limiter), so the loudnorm pass in `mux.sh` has nothing left to reshape; `check()` measures the written mix the way `mux.sh` does and fails the build when loudnorm would have to ride the level. The reason and the numbers to read are at the top of the file. Used by the `mix.py` of all three demos (for example [`styles/atlas-scroll`](../styles/atlas-scroll/demo/mix.py)).
- `audio/cues.py`: lets a film's `mix.py` read the picture's events by name and checks that the score lands on them. Sounds driven by the picture take their time from the event; an accent written on the music grid names the event it belongs to; `report()` prints every cue with the distance between score and picture and fails the build when one is more than half a frame off. It works from `events.json` alone, so any style can use it. Used by the `mix.py` of all three demos (for example [`styles/atlas-scroll`](../styles/atlas-scroll/demo/mix.py)).
