## 故事与结构

一辆篷车带着地图往西走；走到一半，在它身后长出来的铁路追上了它。

- **铺垫（0–22 秒，1776–1848）。** 卷子从大西洋一头展开，十三州在三秒之内上完色。篷车沿国家公路翻过阿巴拉契亚到圣路易斯；路易斯安那购地让卷子一下子展到落基山；篷车走上俄勒冈小道，在南山口停一拍，走到太平洋。
- **转折（22–34 秒，到 1869）。** 回头往东看，铁路一年一年追上来。一列火车从奥马哈出发，两条线在一个小节头上于普罗蒙特里接轨，火车超过第二辆篷车。从这里起带路的是火车。
- **结尾（34–56 秒，到 1959）。** 铁路网铺满，最后几块领地变成州，四十八。一次拉远到整卷；一次静默之后，两块小牌子盖上去，阿拉斯加和夏威夷，计数到五十。片名出现在大西洋上的花框里。

用到的招牌动作：颜色落定（48 次）、跳进（1803）、行旅交接（1869）、网络按日期生长（到 1912）、计数（全片，最后两个留到静默之后）、附图（1959）。

## 配乐结构

120 BPM，G 大调，原创；一小节 2 秒，从 1.0 秒起，所以 3、9、15、31 秒都是小节头。

- **0–3 秒**：十三州每亮一个拨一个班卓音（一串上行的五声琶音），一个低音，一记扫弦。
- **3–9 秒**：吉他一三拍低音、二四拍扫弦，口琴一句。
- **9 秒**：购地，一把大的扫弦；之后只弹半小节。
- **15–22 秒**：只有吉他分解和口琴，下面垫风声；**19.55–20.4 秒**南山口静默；一个口琴音重新起头。
- **22–31 秒**：低音和吉他回来，班卓先滚八分音符，27 秒起滚十六分，刷子加倍，29 秒起踏脚越来越密。
- **31 秒**：全片最重的一下（踏脚、满把扫弦、道钉）。**31–42 秒**：全体合奏，班卓十六分，口琴旋律；各州的音继续在上面一个个拨出来。
- **42–46 秒**：两个长和弦；**46.0–46.6 秒**静默；**46.6 和 47.2 秒**两记戳，各带一个班卓音；**49.5 秒**最后一个 G 和弦，口琴三个音收尾。
- `mix.py` 打印的各路电平（这支片子）：配乐 −24.0 dB，混响 −33.5 dB，拟音 −29.0 dB，环境 −40.2 dB（均方根）。成片响度 −13.9 LUFS。`mix.py` 的最后一步是 `neo/audio/master.py`：整条混音只加一个增益到 −14 LUFS，只把拨弦和重音的峰值收短，各段保持写的时候的强弱（两记戳仍是最重的一下；按峰值归一的混音过了响度那一步，它们反而成了最轻的一段）。每个重音都声明了它属于画面的哪个事件（`neo/audio/cues.py`）：六个卡点，与画面全部相差 0 ms；48 个州的音、两记戳和片名的时间直接取自事件。

## 配色与道具

STYLE.zh-CN.md §3 里的示例配色就是这支片子的。数据：48 个州共 94 版边界，领地 111 版，美国国土的外廓 26 版（1776–1912），1913 年以前通车的铁路 9,836 段。最初十三州从 1776 年起就按 1783 年的边界显示，按批准宪法的先后亮起；其余各州取它在 OpenHistoricalMap 里第一版边界的起始日期，只有德克萨斯例外：更早叫这个名字的是墨西哥的省和共和国。

行旅：一辆两头牛拉的篷车（国家公路，然后是俄勒冈小道，经卡尼堡、烟囱岩、拉勒米堡、独立岩、南山口、霍尔堡、博伊西堡和达尔斯）；犹他的第二辆篷车；一台带三节车厢的机车（奥马哈到普罗蒙特里到萨克拉门托，然后圣保罗到西雅图）。它们的位置是大致的，沿着有名的地点走，不是实测的线路。

地图视角：北美洲北纬 22° 到 52°，Albers 等积圆锥投影（标准纬线北纬 29.5° 和 45.5°，原点西经 96°、北纬 37.5°）。只画美国、它的各州和各领地的边界；其他陆地是素纸。

## 构建笔记

| 文件 | 画什么／做什么 |

| `demo/atlas.js` | 画法：纸、晕滃小丘、篷车、机车、罗盘、大写字、星、牌子 |
| `demo/main.js` | 数据 → 各年的版本、邻接着色、地图、行旅、纸卷、牌子、声音事件、`window.render` |
| `demo/mix.py` | 配乐、拟音、环境声和总线 |

| `demo/FACTS.md` | 屏幕上的每个年份和它的来源 |
| `demo/build.sh` | 按顺序做完全部步骤，包括取数据的命令 |

- 构建：`sh styles/atlas-scroll/demo/build.sh vNNN`，取下一个空号（导出事件 → 混音，含卡点核对和电平检查 → 24 帧、4 个进程渲染画面 → 按 −14 LUFS、BT.709 合成 → 文字停留检查 → 53 秒的海报和 31.3 秒的风格图）。每次构建都是新版本，不覆盖任何东西。
- 渲染时间：苹果芯片笔记本、4 个进程，1,344 帧约一分钟；混音约一分钟。
- 审片：每 2.8 秒一帧，然后在 0.3–2.4 秒（展卷）、19.4–20 秒（南山口）、30.6–31.4 秒（相遇）、46.6–50.4 秒（计数和片名）附近逐张看。
- 这支片子踩过的坑：
  - 对全国用正则查河流超时了两次；五大湖只能两个两个取，东部的山峰只取了阿巴拉契亚南段。
  - `--bbox -128,…` 被当成了选项；要写成 `--bbox=-128,…`。
  - 最早的片名花框挂在图幅外面；现在按图幅坐标放，不按经纬度。
  - 第二辆篷车正好站在火车底下；它的路线往南挪了半度。
  - 中西部的铁路把州名埋掉了，直到铁路的不透明度跟着缩放走。
  - v001 里年份牌在字幕下面照常走：字幕还写着“1869”，牌子已经到了 1877。v002 起年份的关键帧保证字幕在屏时最多走一年（`timeline.js` 里的 `YEAR`）。
