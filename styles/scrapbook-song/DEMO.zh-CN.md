# 手账歌谣 — 我们的示范片

这只是许多可能中的一个例子。不要沿用它的故事、结构、镜头、道具或时间。

示范片：《风吹新竹》*Wind Through Hsinchu*（48.5 秒）· `scrapbook-song.mp4` · 源码在 [`demo/`](demo/) · English: [DEMO.md](DEMO.md)

歌曲：《风吹新竹》，词曲演唱 hoy neo（2026）。示范片是为这首歌做的手绘 MV 里的 48.5 秒：同一批画和时间轴，用同一套 Python 重新生成（现在就是这个风格的工具包 [`kit/`](kit/)），按本库的页面约定播放。示范片的文件夹本身就是用工具包做的一个工程，和用户的片子做法一样（[`PRODUCTION.zh-CN.md`](PRODUCTION.zh-CN.md)）。新竹的地标和吃的按大致样子画，不是任何地方的官方形象。

## 故事与结构

这首歌：一个在"风城"新竹长大的孩子，被风吹向海边、吹向很多城市，最后吹回家。示范片取桥段和最后一遍副歌（全曲 146.64–190.60 秒），加一张片尾卡。

- **分开（0–9.5 秒）。** 两个朋友在两座城市，一边下雪的夜，一边棕榈树的晴天，各自看着手机；一只纸飞机穿过锯齿形的分界。一条风带；然后俯视行李箱，家乡的东西随拍落进去：米粉、柿饼、风筝、旧车票、合照、竹叶。
- **一阵风（9.5–17.8 秒）。** 灰蓝的异国街道，长大的主角走着，一阵风夹着一片家乡的竹叶吹过，主角停住。然后是安静的一页：把海螺贴在耳边，"我还是听见那年的海浪"竖着写下来，强拍上盖下"风城"印章。
- **副歌（17.8–34 秒）。** 玫红放射纹底上的特写，底鼓上爆炸云炸开，"风吹新竹"砸下来，对话框里一个"啊"，两张标签；风带切到海岸，机车从东门城骑向海边，车票，黑缎带；入夜，五栋楼一下子立起来，标题横着砸过夜空又被吹走，拖着行李箱的人走过，窗在半拍上一簇簇亮起，吊牌和缎带。
- **家（34–44 秒）。** 风把窗吹暗；镜头钻进最后一扇亮着的窗；窗里有汤和柿饼，那句话自己写出来，"家"在军鼓上砸下。然后是剪贴簿那一页：两人在海边的拍立得、胶带、车票、手写的"hoy neo"、"风吹新竹"印章。一条玫红风带。
- **片尾卡（44–48.5 秒）。** "NEO-Cine"一个字母一个字母砸下，"手账歌谣"印章，歌在下面淡出。

用到的招牌动作：东西落进容器（行李箱）、分屏、安静一页上的竖排字、爆炸云特写、沿曲线行驶的机车、经过即点亮（窗）、推进最后一扇亮着的窗、拍点上的印章、剪贴簿上的照片、吹走（砸下来的标题）、全程的风带。

## 声音结构

就是这首歌，99.4 BPM，4/4。片段从桥段（全曲最安静的地方）开始，升进最后一遍副歌，最大的反差是歌自己带的。开头淡入 0.25 秒，最后 2.6 秒淡出（歌的尾奏在片尾卡下面继续）。不加任何声音。`mix.py` 用一个增益把它定到 −14 LUFS（原曲这一段 −14.6 LUFS，限幅器只工作了 0.1% 的时间），并核对画面上 13 个重拍（6 次行李落下、"风城"印章、爆炸云、闪光、"家"、"风吹新竹"印章、片尾砸字、片尾印章）都落在歌的拍点或鼓点上：最大偏差 8 毫秒。

## 色板与道具

纸 `#F3EDE0`、墨 `#191919`、玫红 `#E8457A`、青 `#3FB8A4`、黄 `#F5D03B`、朱红 `#C8352E`、夜蓝 `#1E2A78`、橙 `#F08A3C`、竹绿 `#3E8E5A`、米黄 `#F2D08B`。底色顺序：夜蓝/橙分屏 → 纸 → 灰蓝 → 纸 → 玫红 → 青 → 夜蓝 → 黄 → 纸 → 纸。主角：黑色短发，白衬衫或橙色外套，**黄围巾**（风和光的颜色）；朋友：长发，粉色发夹。风永远从右往左吹。来自歌词和新竹的道具：米粉、柿饼、风筝、写着"东门城 → 海岸"的旧车票、心形石沪、招潮蟹、东门城、贡丸米粉汤。

## 片尾卡

米白纸、风卷、一片竹叶；190.82 起 **NEO-Cine** 用大字体一个字母一个字母砸下，192.03 盖下红色印章 **手账歌谣**（风格名）。没有别的。歌名和演唱者留在原 MV 放它们的地方：这首歌自己的片名页（剪贴簿那一页，第 9 镜），作为作品信息。用户自己的片子不署 NEO-Cine，也不照搬这张卡。

## 构建说明

```
demo/                       一个手账歌谣工程，和用户的片子一样
  mv.json                   片名、歌的片段（audio_t0 146.0）、range 146.64–195.20、镜头表、重拍、pass_texts、海报
  audio/song-excerpt.mp3    片子用到的那 50 秒歌（进 git）
  data/                     lyrics.json（48 句和时间）、audiomap.json（原 MV 的节拍分析，见 CREDITS）
  scripts/scenes/           full_s18、full_s19、build_f1–f4（原 MV 的镜头）、end_card
  scripts/assets/           hd_people、props2、city（这首歌的画）、songlib（它的道具和这一段的页码）
  build.sh                  sh styles/scrapbook-song/demo/build.sh v002（RENDER=remote 用台式机 GPU 渲）
```

`build.sh` 把示范片当作工程交给工具包的 `tools/make.sh`，成片和海报写到风格目录（`OUTDIR`）：镜头 → 字体（子集跟着镜头里的字走）→ 事件 → `tools/mix.py`（截歌、淡入淡出、重拍核对、−14 LUFS）→ 渲染 → 合成 → readcheck、lyriccheck → 海报（38.5 秒）；然后风格帧（21.7 秒），画廊副本缺了才复制。在台式机上渲 1165 帧（RTX 4060 Ti，4 个 worker）约 100 秒，再加编码。

- **原高潮版的四个镜头**（`build_f1`–`f4`）的时间轴是手写的，没走 `Scene`，所以它们的重拍列在 `mv.json` 的 `hits` 里；`songlib.tag` 把它们原来写的「n / 6」页码换成这一段的页码。
- **节拍分析** `data/audiomap.json` 用的是原 MV 当年对拍的那一份（librosa）；新片子用 `tools/analyze.py` 自己分析，它在这首歌上和原来的强拍、波形上的起音都只差几毫秒。
- **相对原 MV 的改动：** 页码按这一段重编（01–09）；剪贴簿那一页多停 0.7 秒，让"风吹新竹"印章在画面上停 2.8 秒；片尾卡是新画的。其余都由原代码原样生成（核对过：SVG 和时间轴一样）。
- **检查（v001）：** `readcheck` 0 BAD（计时 17 块；页码、运送途中的车票和"风城"小印章记为 pass，理由写在 `mv.json` 的 `notes`）；`lyriccheck` 12 句、0 句不合格——每一句在唱完时都已完整——另有沿用原 MV 时间的注意项：第 41、46 句完整后只停 0.6 / 0.5 秒就切镜头，第 43 句的缎带只停 0.12 秒，第 47 句（家）比最后一个长音唱完早 2 秒离开，多数句子停留不到 max(1.8 秒, 演唱时长 + 0.6 秒)；重拍核对 13 个，最大偏差 8 毫秒；`mux.sh` −13.9 LUFS；没有黑帧。
- **这部示范片的坑：** f4 的推镜头把一组画放大 31 倍；它的位移滤镜用的是用户空间的边界（`f4-wobZ`），否则抖动会跟着放大。
