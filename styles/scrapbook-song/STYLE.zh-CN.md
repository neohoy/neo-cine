# 手账歌谣 — 风格提示

*来自《风吹新竹》手绘 MV 和为它做的那套制作工具。English: [STYLE.md](STYLE.md)*

> 一格一格画出来的赛璐璐卡通：粗墨线、饱和平涂、硬墨色投影，所有线条一直在抖，画出来的动作一拍两张。唱的或说的字按音节一个字一个字打出来，**写在画面里的东西上**（纸标签、黑缎带、招牌、对联、路牌、印章、夜空），或者在重拍上用大字砸下来，整页像贴满贴纸、胶带和印章的拼贴本。画面每次都按这段文字重新画。
> 参考（只学语法）：手绘歌词视频和 zine 拼贴（字贴在物件上、贴纸、胶带、橡皮章）；有限动画的电视卡通（一拍两张、换画表演、落地压扁、速度线）；漫画格（对话框、爆炸云、四格）。不照搬它们的角色、版式、字体和音乐，片子里也不提它们的名字。

需要：库的核心工具（numpy、scipy、fonttools、pillow；ffmpeg；无头浏览器）。用户的歌和带时间的歌词（LRC）。繁体片要 OpenCC（`opencc-python-reimplemented`），装在工程里（`<工程>/.pylib`）。字体由工具包下载（OFL）。其余都在 [`kit/`](kit/) 里：这个风格的片子按 [`PRODUCTION.zh-CN.md`](PRODUCTION.zh-CN.md) 一步步用它做。

## 1. 本质，以及它不是什么

- **一种墨，一种粗细。** 每个形状都用同一种近黑的墨线描边（1920 宽时 7 px），圆角接头；粗的东西（四肢、围巾、道路）是一条墨色描边上压一条彩色线。除了光晕和纸纹，没有不描边的东西。
- **平涂和硬投影。** 填色只用单一平色，不用渐变；立体感靠向右下错开 10–14 px 的实心墨色投影。
- **一切都在抖。** 画出来的线每 1/12 秒在三个噪声种子之间轮换重抖；字抖的幅度约一半，保证认得清。
- **字住在东西上。** 一句话随唱逐字打出，写在画面里本来就该有的载体上；副歌的钩子或关键字用大字砸下来。不做 KTV 逐字变色，不放字幕条。
- **画面从字里来。** 每个画面里至少有一样东西直接来自屏幕上那句话（抽象词找一个能画的替身）；角色、道具、地点都按文字设计，不搬别的片子的。
- **一个有方向的母题。** 一样反复出现的东西（风、雨、一盏灯、一条路、一列火车）带着全片走，永远朝同一个方向穿过画面。

不是蜡笔绘本（没有蜡笔纹理和水彩晕染：填色是平的），不是橡皮管卡通（没有 1930 年代的黑白弹跳和切角眼），不是动态排版（字从不浮在空底色上，它们落在画出来的物件上），不是矢量讲解片（没有渐变、发光、HUD 和图标），不是幻灯片（任何地方都不放照片）。

## 2. 材质与渲染

- **代码生成 SVG，一个镜头一份。** 一个镜头是一张 SVG（视框 1920 × 1080）加一条补间时间轴；Python 用一个个小函数拼出画，页面按任意时刻 t 算出时间轴的状态。
- **一个镜头的图层：** 底色 → 套着位移滤镜的画（湍流，基频 0.022，幅度 6）→ 套着更轻滤镜的字（0.035，幅度 3.2）→ 纸纹（分形噪声，基频 0.8，深底不透明度 0.35，浅底 0.45–0.9，合成在它自己的矩形之内，隐藏的镜头就不会画出纸纹）→ 页码。
- **抖线是程序化的，每个镜头各自一套。** 每个镜头有自己的三个滤镜（id 带镜头前缀），种子每 1/12 秒按 1→2→3 轮换。不要在脚本里用随机偏移来抖。
- **形状：** 描边的路径、圆、多边形；云是几个圆的并集，只描一圈外轮廓；爆炸云是带固定种子抖动的星形多边形；风卷是一笔开放的线。卡片、招牌、板子是一个矩形加它的错位墨色投影。
- **人物是参数化的：** 头半径 r 决定整个人；正面（发型、眼睛、嘴、手势、腿长）、侧面走路（两张腿的画轮换）、背影、骑车。同一个角色换年龄时保留发型、标志色和配饰，只改头的大小和腿长。
- **不用照片、扫描、贴图和渐变。** 光是一块平的黄色；夜是平的深底色上一格格亮着的窗。

## 3. 色彩逻辑

- 暖米白的纸和一种近黑的墨是不变的。在这之上：几种饱和的平色（玫红、青、黄、朱红、橙、竹绿、夜蓝、米黄）。
- **每组镜头一个底色**，相邻两组的色相或明度拉开；钩子或副歌用最饱和的底色；开头和结尾可以回到纸色。
- **主角的标志色**全片不变，并且和母题共用（我们的示范片里，围巾、风和光是同一种黄）。
- **字的颜色按固定配对轮换**（纸/墨、墨/纸、黄/墨、玫红/白、青/白、红/黄、白/墨、橙/墨），相邻两张标签不会同色。红色留给印章和砸下来的大字。
- 墨从不换成灰色，也不换成填色的深一号。
- 示例（我们的示范片）：纸 `#F3EDE0`、墨 `#191919`、玫红 `#E8457A`、青 `#3FB8A4`、黄 `#F5D03B`、朱红 `#C8352E`、夜蓝 `#1E2A78`、橙 `#F08A3C`、竹绿 `#3E8E5A`。

## 4. 字体与字幕

- **两种字体干活**（OFL，按用到的字切子集）：圆润的大字体用于砸字、缎带、印章（简体用站酷快乐体 ZCOOL KuaiLe；繁体用 Chiron GoRound TC 900，站酷快乐体没有繁体字），手写楷体用于唱的句子和标签（霞鹜文楷 LXGW WenKai TC）。等宽字体用于页码和车票号，意大利斜体衬线用于手写签名。
- **1080p 下的字号：** 句子和标签 70–96 px，竖排板子 70–80 px，砸字 160–240 px，配 14–20 px 墨色描边和 10–14 px 硬投影，小字（页码、车票）22–38 px。
- **字就是字幕。** 没有单独的字幕轨，也没有底部字幕条：每一句写在画面里的一个载体上，一句一个载体：

| 载体 | 适合 |
|---|---|
| 普通打字（深底上用白字加墨边） | 任何一句 |
| 带胶带、微微倾斜的纸标签 | 安静的一句 |
| 两头分叉的黑缎带，大字体 | 一句宣告、一段的最后一句 |
| 竖排店招、吊牌、黑板菜单 | 街道、店铺、吃的、教室 |
| 一对红对联（先右后左） | 门口、庙、节日 |
| 挂在上方的绿色路牌 | 公路、旅途、距离 |
| 只装一个大字的对话框 | 喊声、唱出来的"啊" |
| 在拍点上盖下的红印章，溅出墨点 | 标题、地名、落款 |
| 一颗流星在天上写字 | 夜晚、愿望、名字、约定 |
| 从嘴里或窗里飞出去的字贴纸 | 笑声、吵闹、被风吹走的话 |
| 砸字：大字一个个落下、压扁、站稳 | 钩子、一个关键字——每个镜头最多一处 |

- **打字跟着声音走：** 每个字在它的音节之前弹出来（0.25 秒，从 0.3 倍带一点旋转，回弹缓动）；没有逐字时间时，把字均匀铺在演唱时长的前 72%，每个字提前 0.04 秒。宁早勿晚。不做逐字变色。
- **阅读：** 一句话最晚在它最后一个音节唱出时已经完整、整块在画面里，并且一直完整到这句唱完；唱完以后风才可以把它吹走。尽量让它完整停留 ≥ 0.6 秒，总停留 ≥ max(1.8 秒, 演唱时长 + 0.6 秒)；最后一个长音可以拖过镜头切点。别的字按阅读时长规则（`readcheck.mjs`）。
- **全片一种字形：** 简体或繁体，不混用；整句转换，不逐字转换（转换要靠上下文）。

## 5. 动作质感

- **画出来的动作一拍两张（12 fps）：** 每个补间的进度先按 1/12 秒取整再过缓动。只有摄影机效果是平滑的：淡出到黑、2 帧的闪白。推镜头推的就是画出来的那一页，所以它也跟着画一起跳。
- **换画，不变形：** 走路每 1/6 秒换一张腿；头发和围巾三张画轮换；飘动和上下颠是一步一步的变换状态。
- **落地要压扁：** 砸下来的字、盖下的章、落地的东西先压扁 1/12 秒，再回弹站稳。快速移动加速度线，不用运动模糊。
- **重拍落在音乐上：** 换底色、砸字、盖章、落地都落在拍点或鼓点上（误差不超过半帧）。连续的动作（走、飞、骑）按秒算，不追拍。
- **换组和切镜头**落在下一句开唱前约 0.2 秒，或者落在强拍上。
- **母题的方向全片不变**（头发、围巾、叶子、纸片和被吹走的字都往同一边去）。
- **什么不动：** 地平线和画框；正在被读的字只抖、不走。

## 6. 镜头语法

画面大多是一张锁定的页面，动的是画。下面是一组词汇，不是路线；开头和结尾由题材决定。

| 镜头 | 表达什么 | 可以用在 |
|---|---|---|
| 锁定的全景 | 整页 | 交代一个地方；一句话和它的物件 |
| 爆炸云或放射纹底上的特写 | 情绪开到最大 | 钩子；喊；笑 |
| 推进一扇窗或一样东西直到铺满，再换组 | 走进去 | 从外到里；一段回忆；家 |
| 整个世界往下滑，一样东西留在原处 | 向上摇 | 风筝升起；入夜；结尾 |
| 中间一条锯齿墨线的分屏 | 同时两个地方 | 距离；两个人；那时和现在 |
| 2×2 四格，一格一句 | 一串很快的事 | 短句主歌；一天的例行公事 |
| 俯视一个容器 | 收拢 | 打包；收集；一份菜谱 |

近景里的主要人物至少占画面高度的三分之一；载体从不挡脸。转场：**风带**（一条波浪边、带风线的色带 0.25 秒扫过画面，颜色取下一组的底色）、落在拍点或句首前的硬切、冲进钩子的 2 帧闪白、推进去。不用叠化，不用整屏摇晃，不用手持漂移。

## 7. 声音

- **字自己的声音就是配乐。** 歌词片用歌本身，不做改动：不在上面另加底乐或音效。截取的片段起止处淡入 0.2–0.3 秒、淡出 2–3 秒。
- **说出来的字**（一首诗、一句口号、一段旁白）：一把温暖的人声，底下一层轻的拨弦或玩具钢琴；画出来的重拍配短而干的拟音（标签拍上去是纸声，盖章是木头声，风带是一声轻的呼）。
- **画面跟着声音剪：** 先分析音轨（节拍网格、强拍、鼓点），每个重拍都放在上面。
- 静默是一张停住的画，只剩抖线在动；全片一个增益混到 −14 LUFS。

## 8. 这种媒介才有的动作

- **经过即点亮。** 人走过时灯笼或窗一盏盏亮起，每一盏吸附到下一个半拍。*适合：* 夜里走回家；一条街的店陆续开门；列车开过站台。
- **身高刻度。** 门框当身高尺：每个强拍换一张更大的画，铅笔标出年份。*适合：* "长大"；一家公司的这些年；校园里的一棵树。
- **撕页日历。** 每拍一页被风撕走，窗外的天色轮换。*适合：* 等待；纯音乐的间奏；倒计时。
- **东西落进容器。** 俯视的行李箱、篮子或盒子；每样东西在拍点上从 1.7 倍落下并压扁。*适合：* 打包离开；一份菜谱；一座城由什么组成。
- **分屏。** 两个地方并排，中间一条锯齿墨线，一只纸飞机或一条虚线弧穿过去。*适合：* 异地；两份工作；白班和夜班。
- **四格漫画。** 一格一句短词，每格在它那句前 0.28 秒砸进来。*适合：* 一天的作息；四个理由；一串家务。
- **大笑特写。** 放射纹上的两张大脸，头发三张画轮换，字贴纸从嘴里飞出去。*适合：* 一群朋友的合唱；欢呼；一句笑点。
- **拍点上的印章。** 竖排红印章盖下来，压扁，溅出墨点。*适合：* 地名；标题；落款。
- **推进最后一扇亮着的窗。** 镜头按指数缓动钻进一扇窗；窗里，这句话的关键字落下来。*适合：* "家"；深夜还亮着的办公室；一间病房。
- **照片活过来。** 剪贴簿里贴着胶带的拍立得铺满画面，开始动。*适合：* 一段回忆；前后对比；一个家的故事。
- **吹走。** 一句话唱完以后，母题把它的字一个接一个带出画面。*适合：* 一段的结束；换场景；放下。

## 9. 这种媒介的坑

- **浮着的字。** 打在空底色上的一句话看起来就是动态排版：给它一个画面里的载体。
- **通用画面。** 用一颗心、一个地球、一束光去画抽象词：找这句话自己暗示的具体替身（"答案"画成咖啡面上映着凌晨三点的钟）。
- **KTV 习惯。** 整句逐字变色、底部字幕条、没唱完就消失的句子：都不许。
- **到处砸字。** 一个镜头砸字超过一处，钩子就不突出了。
- **跳帧不安全的时间轴。** 每一帧都是单独、乱序渲出来的：一个元素只用一个变换原点；大位移放在只管平移的外层（或者补间在 Python 里算好的 transform 属性）；被补间的元素自己不能带 transform 属性；时间轴里不放随机数和时钟（在 Python 里用固定种子生成）；所有表达式先在 Python 里算出结果再写进脚本。
- **隐藏的镜头照样画滤镜。** 湍流滤镜在 visibility 隐藏时照样会画：不在画面里的镜头整个拿掉（display none），纸纹合成在它自己的形状里。
- **缺字。** 子集字体缺字时会悄悄换成别的字体：按实际印出来的字切子集，缺任何一个字就停下。
- **相邻同色**（两个底色、两张标签）：轮换开。
- **平滑的移动配跳着的画。** 推、移每帧都平滑，画却一拍两张，看起来像贴上去的：让它跟着画一起跳（只有淡出和闪白保持平滑）。

## 10. 引擎

[`kit/`](kit/) 里的工具包能从一首歌做出整支片子，[`PRODUCTION.zh-CN.md`](PRODUCTION.zh-CN.md) 是制作手册：建工程、分析、意象表、素材表、分镜、镜头、样片、渲染，以及三个要用户确认的地方。看代码，这里不复述。

- 画（Python，镜头脚本导入）：`scene.py` — `Scene(fid, p, bg)`：全曲时间和镜头内时间互换（`L`），逐字出现的字（`chars`、`pop_chars`、`line`），`blow_chars`，风带（`band`、`band_in`、`band_out`、`band_through`），`wob`/`wobT`/`grain`，`group`，`hit`，`write`。`typo.py` — 载体（`typing`、`slam`、`label_line`、`ribbon_line`、`sign`、`couplet`、`chalk_board`、`road_sign`、`bubble`、`seal`、`sky_write`、`hang_tag`、`spill`、`blow_off`、`tape`）。`draw.py` — 铅笔（`shape`、`thick`、`shadow_box`、`drawable`、脸、`person_front`/`person_side`/`person_back`/`bike`、天空、天气、植物、建筑）。`hd_lib.py` — 色板、`T`/`VT`、`label`、`ribbon`、`puff`、`burst`、`curl`、`leaf`、`sparkle`、页码 `tag`。`frame_kit.py` — 抖线和纸纹滤镜、12 fps 的脚本小工具（`q`、`pop`、`cycle`、`jitter`、`boil`）。`music.py` — 歌的节拍和歌词时间；`project.py` — 工程的 `mv.json`；`text.py` — 简繁。
- 播放：`kit/page/` — `gsap-lite.js`（把镜头时间轴当作时间的纯函数来算）、`film.js`（挂载镜头，提供页面约定）、`index.html`；由 `tools/build.py` 复制进工程。
- 工具（`kit/tools/`）：`new_project.py`、`analyze.py`（节拍、强拍、鼓点、能量；numpy 和 scipy）、`lyrics.py`（LRC）、`repeats.py`、`asset_sheet.py`、`build.py`、`fonts.py`、`preview.sh`、`mix.py`、`make.sh`、`lyriccheck.mjs`。模板在 `kit/templates/`。
- 示范片（[`demo/`](demo/)）本身就是用这个工具包做的一个工程；它自己的画和镜头在 `demo/scripts/`。

一个示范片里没有的镜头，教室里写在黑板上的一句（某个工程的 `scripts/scenes/s03-class.py`；起止时间从 `mv.json` 取）：

```python
from scene import *; import typo
from draw import *          # 铅笔：人物、天气、建筑、shadow_box……
sc = Scene("s03-class", "cl", BUFF)
kid = person_front(560, 520, 70, hair="bun", top=WHITE, bottom=NAVY, arms="wave", legs=.8)
body = (sc.wob(rect(0, 820, 1920, 260, "#B7804F") + kid)
        + sc.wobT(typo.chalk_board(sc, "cb", li=12, x=1240, y=140) + typo.seal(sc, "se", "下课", 300, 220, 64, 31.2))
        + sc.grain(.4))
sc.write(body)
```

## 11. 变化空间

每部片子自己定：文字和它的时间从哪来（一首歌、一段录好的人声、朗读的一首诗），角色和道具（从文字里来），母题和它的方向，底色的顺序，每一句写在哪种载体上，镜头和转场，简体还是繁体。

不只是歌词 MV（字来自一段录好的人声时：转写出逐字时间，TECHNIQUE.md §4，当作一首没有配乐的歌来做）：一首诗或一句口号，写进它点到的那些地方；一段城市或校园宣传旁白，每句话写在它说的那样东西上；生日或婚礼祝福；一个品牌的创业故事；一首儿歌。

- **结构：** 从清晨到夜里的一天，一个钟点一组；一串地点，每个地点一种载体；分屏两边的两个人一问一答。
- **开头：** 一道母题的铅笔线划过空白的纸；爆炸云底上砸下标题；一张吊牌落进空荡荡的街。
- **结尾：** 镜头往上摇进夜空，星星把标题写出来；行李箱合上，收起攒下的一切；最后一扇窗熄灭，只剩一个字还亮着。
