# 舆图长卷：我们的示范片

*本文是 [DEMO.md](DEMO.md) 的中文版，以英文版为准。*

这只是众多可能中的一个例子。不要照搬它的故事、起伏、镜头、道具或时间点。

示范片：《鹏城长卷》（Shenzhen, Unrolled，48 秒）· `scroll-map.mp4` · 源码在 [`demo/`](demo/)

这是一支关于真实地方的非官方影片。地图是 OpenStreetMap 数据（© OpenStreetMap contributors，ODbL 1.0），画成示意图，不是测绘成果。

## 故事与结构

一支笔想把深圳的海岸从头画到尾；画到一半，这座城长得比笔还快。

- **铺垫（0–17 秒）。** 卷子从东头展开。墨线勾出大鹏半岛，山立起来，海湾铺满浪纹。大鹏所城（“鹏城”这个别称的来历）是纸上唯一的城，它的贴签是这一段唯一的朱砂。
- **转折（17–37 秒）。** 镜头加快往西，掠过梧桐山。到了罗湖，朱砂从口岸冒出来，沿路网散开；福田中心区的高楼长成一层层的楼阁，平安金融中心最后、最高。
- **结尾（37–48 秒）。** 一次拉远到整幅卷子，剩下的部分同时展完、画完。片名写在右端的留纸上，盖印。开场是第一笔，结尾是一方印。

用到的招牌动作：展卷（开场和揭示）、笔在前面走（半岛）、山立起来（全片）、朱砂散开（转折）、高楼画成楼阁（标志性镜头）、贴签和盖印（所城、结尾）。

## 配乐结构

60 BPM，D 羽调五声（D F G A C），原创；所有落点都在整秒或半秒上。

- **0–13 秒**：1.0 秒一个低的散音，3 秒一个泛音；然后是稀疏的、带滑音的古琴句子，箫 8 秒进。
- **13.3–14.5 秒**：几乎无声（只有浪）；所城的签落在一个泛音和一个低音上。
- **17–24 秒**：古琴走连续的八分音符，箫吹长线，鼓 20 秒进，到 24 秒前密到十六分。
- **24 秒**：全片最重的一下（鼓、低弦、一把五度的拂）。之后是琵琶的十六分音符，下面是鼓和鼓边，每两小节一个古琴低音，上面是箫；33.5 秒琵琶升一个八度。
- **32–35 秒**：平安金融中心每长一层敲一下木鱼，一路往上。
- **37 秒**：古琴一把往下的拂；箫的长音 D 压过整个拉远。
- **42.2–43.7 秒**：每写一个字一个古琴音。**44.25–44.8 秒**静默。**44.8 秒**盖印（鼓、木鱼、闷响），之后两个泛音慢慢散掉。
- `mix.py` 打印的各路电平（这支片子）：配乐 −22.4 dB，混响 −27 dB，拟音 −29 dB，环境 −32 dB（均方根）。成片响度 −14 LUFS。`mix.py` 的最后一步是 `neo/audio/master.py`：整条混音只加一个增益到 −14 LUFS，只把峰值收短，安静的开头仍然安静，朱砂仍是最重的一段。每个重音都声明了它属于画面的哪个事件（`neo/audio/cues.py`）：六个卡点（14.5 秒贴签、24 秒朱砂、卷轴停住……），与画面全部相差 0 ms；楼阁每一层的木鱼、笔声和盖印的时间直接取自事件。

## 配色与道具

STYLE.zh-CN.md §3 里的示例配色就是这支片子的。贴签：浅色 `#f2e8cc` 加朱框；两座古城（大鹏所城、南头古城）用朱签。印文：深圳。山来自 3,040 块林地和 60 米以上的有名山峰；楼阁来自福田中心区的 4,868 个建筑占地，其中 1,357 个带高度。

地图视角：沿海一条，东经 113.74–114.66°、北纬 22.40–22.74°，北朝上，不画任何界线；画面下缘的新界和其他地方画法完全一样。

## 构建笔记

| 文件 | 画什么／做什么 |
|---|---|
| `demo/index.html` | 字体和画布 |
| `demo/timeline.js` | 唯一的时间来源：镜头关键帧，纸卷、设色、朱砂三条前沿，楼阁的时间，片名，地名 |
| `demo/ink.js` | 画法：纸、浪纹、墨线、山、屋宇和楼阁、贴签、印章 |
| `demo/main.js` | 数据 → 路径和符号，各图层和它们的前沿，卷子和纸卷，声音事件，`window.render` |
| `demo/mix.py` | 配乐、拟音、环境声和总线 |
| `demo/data/coast.json`、`futian.json` | 地图，由 `neo/geo/osm.py` 生成（命令在 `build.sh` 里） |
| `demo/tools/fonts.sh` | 下载两款字体 |
| `demo/build.sh` | 按顺序做完全部步骤 |

- 构建：`sh styles/scroll-map/demo/build.sh vNNN`，取下一个空号（导出事件 → 混音，含卡点核对和电平检查 → 24 帧、4 个进程渲染画面 → 按 −14 LUFS、BT.709 合成 → 文字停留检查 → 47 秒的海报和 36 秒的风格图）。每次构建都是新版本，不覆盖任何东西。
- 渲染时间：苹果芯片笔记本、4 个进程，1,152 帧约 90 秒；混音约 50 秒。
- 审片：每 2 秒一帧，然后在 0–1.6 秒（展卷）、24–25.6 秒（朱砂）、44.6–45.6 秒（盖印）附近按 0.2 秒一格看。
- 这支片子踩过的坑：
  - 遮住纸卷以西的那个裁剪矩形，从屏幕外的起点算只有 `W` 宽，近景全成了白纸。
  - 南边的鱼塘看着像灰色的楼，直到水体的描边按缩放变细。
  - 最早的山太尖，像松树：山脊的曲线改成了外凸的。
  - 细碎的建筑部件挤成黑块：现在大的符号先占位。
