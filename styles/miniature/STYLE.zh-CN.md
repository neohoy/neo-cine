# 微缩景观 Miniature — 风格说明

*English: [STYLE.md](STYLE.md)*

> 一个地方做成白色的建筑模型，切开放在薄薄的展示底座上，用长焦镜头看：小人和车循环地走，屋顶或楼层抬走露出里面，一层安静的讲解（编号牌、引线标注、一条长出来的点线动线）一步一步讲清楚这个地方是怎么运转的。
> 参考（只学语法）：建筑师的剖切模型和截面模型；铁路模型和它的小人；移轴摄影（清晰带）；博物馆展签和技术书里的分解图（一次只讲一个编了号的东西）。不照搬它们的地点、字体、配色和音乐，也不在片子里提它们的名字。

需要：库的核心工具（three.js r170 和库 `node_modules` 里的插件；声音用 numpy、scipy、numba）。做真实地点时用 `neo/geo/buildings.py`（OpenStreetMap；Overture 需要 `duckdb`，见 [`neo/requirements-geo.txt`](../../neo/requirements-geo.txt)）。不用图片和模型文件：`demo/kit/` 工具包全部用代码搭。

## 1. 本质，以及它不是什么

- **桌上的模型。** 世界在一块薄底座处结束。后面只有平的背景色和底座的软阴影：没有天空、没有地平线、底座以外没有地面。
- **切开看里面。** 至少有一个面是截面：露出楼板的厚度和地面以下的土（沙色，带淡淡的地层）。屋顶、雨棚和上半截立面作为一整块抬走，镜头才看得进去。
- **长焦。** 正交（或接近正交，约 9°）视角：平行的边保持平行，没有透视汇聚，模型读起来是小的。近景加一条移轴清晰带。
- **比例读得出来。** 一层约 6 个单位；一个人约 1.75，是一层的十分之三。人、长椅、闸机、楼梯同一个比例，观众数得清台阶和座位。
- **白模加少量点缀色。** 几乎都是白、象牙白、浅灰；颜色只留给有意义的东西（§3）。
- **它在讲解。** 一次讲一件事，每件事有编号；一个人要走的路先以点线长出来，他再走过去。
- 它不是等轴信息图（没有扁平图标、没有描边、没有等轴投影的把戏），不是像素或体素画，不是玩具（没有亮晶晶的饱和塑料、没有大倒角），不是照片级渲染（没有照片贴图、没有天空），也不是 CAD 漫游（没有第一人称镜头、没有线框）。

## 2. 材质与渲染

- **每个件都有倒角。** 方块都用工具包自己的倒角盒（半径 ≤ 0.06 单位，且不超过最短边的六分之一）；树冠是一簇球；头是球。没有锐利的 CG 棱角，没有面片感。
- **安静的物理材质。** 石材和白模：粗糙度 .72–.8，没有金属度。车漆：粗糙度约 .35，加清漆。栏杆、钢轨的金属：粗糙度 .35，金属度 .8。一个低强度的房间环境（PMREM）给柔和的反光；不出现看得见的 HDRI。
- **玻璃不用 transmission。** 玻璃是偏青灰、低粗糙度、半透明的面（opacity .16–.3，不写深度），亮光来自环境贴图。不用物理透射：在 Windows（ANGLE、Direct3D 11）上它让着色器编译要好几分钟。
- **接触阴影让它变小。** 一个太阳，大而软的阴影贴图；屏幕空间环境光遮蔽（GTAO）限定在模型外包盒里，并且跳过半透明的东西；ACES 色调映射；2 倍超采样加 MSAA。不加颗粒，不描边。
- **移轴是屏幕空间的一道工序**：两遍可分离高斯，模糊半径随离水平清晰带的距离增大。全景几乎不糊（边缘约 3 像素）；近景最多约 7 像素。
- **夜景靠自发光。** 路灯、吸顶灯带、屏幕、车窗、玻璃幕墙登记成会亮的批次，自发光强度跟着天色走；辉光只在夜里开。
- **截面的土**是一种材质，按世界高度画地层（色带、细的层界线、一点颗粒），所以从哪里切开都读得出是地。

## 3. 色彩逻辑

- **中性的底。** 暖浅灰背景；白、象牙白、浅灰的模型。明度有顺序：底座最深（石板色），切开的土居中（沙色），模型最浅。
- **比例（按画面面积）：** 模型的白和灰 80–85 %；底座和土 8–12 %；绿化 4–6 %；点缀色不超过 5 %，同一画面最多三种点缀色相。
- **点缀色有含义。** 一种给讲解（动线和编号牌：金色），如果有第二股人流再给一种（青色），主角的衣服一种（珊瑚色），真实交通线路的官方颜色只用在线路标记上。其余（衣服、车、牌子）都是低饱和的。
- **不画运营方的标志、涂装和字样。** 牌子只有色块和象形图。
- **天黑要经过蓝。** 白天 → 蓝调时刻（冷的蓝灰）→ 深蓝黑；绝不经过棕色。暖的室内灯对冷的夜。
- 没有纯黑，没有饱和或渐变的背景。

## 4. 字与字幕

- **是展签，不是字幕。** 所有字都是中英两行：中文在上（Noto Sans SC，700，1080p 下 26–40 px），英文在下（Inter，500，15–20 px，字距拉开，编号牌上用大写）。两种字体都是 OFL。
- **步骤编号牌**：左上角，一个金色圆牌写编号，旁边是这一步的中英文名字。同一时间只有一块。
- **引线标注**：模型上一个点（白圈金心），一根拐一次的细墨线，画面边上一块纸色的小牌。锚点是世界坐标，每帧投影，所以镜头动的时候标注跟着模型走；先画线，再淡入字。
- **片名卡和片尾卡**：左下角，大号中文片名（约 76 px），一短条金色横线，下面英文大写、字距拉开。
- 阅读时长：每块字都通过 `window.TEXTS` 报告；每块完整可见的时间至少 max(1.5 s, 中文字数 ÷ 4.5 + 其他字符数 ÷ 15 + 1.5 s)。同一步里的标注可以同时出现；步与步不重叠。
- 默认没有旁白。有配音时，字幕是底部居中的一条展签，避开底座。

## 5. 运动质感

- 24 fps，逐帧都动；一切都是时间的纯函数。
- **小人**走路约 1.9 单位/秒（比真人略快，模型尺度下才读得出"在走"），腿和手臂的摆动跟着走过的距离；会停、转身、坐下、排队、站着乘扶梯、上下楼梯步子更碎。少数人站着不动。没有人小动作不停。
- **车**匀减速停到站，匀加速离开（进站 `x = 停车点 − D(1−u)²`，出站 `停车点 + D·u²`），减速前和加速后匀速。从切面里开进开出（裁剪平面），绝不凭空出现。
- **机器像机器那样动**：闸机门翼收回又伸出，扶梯台阶匀速走，门滑开。
- **抬升**（屋顶、楼层）用约 2.5 秒的缓入缓出，落定时一声轻轻的"嗒"；屋顶可以先抬一点（全景里看得见），推近时再升出画面，最后一次落回。
- **灯一下子亮**，约十分之一秒，一批一批地亮。
- **动线**在每一步先往前长出来（约 1.5 秒），人再沿着它走。
- 永远不动的：底座、切面、建筑。不弹跳、不挤压、不晃、不在原地呼吸似的闪。

## 6. 镜头语法

一个镜头是 `{target, yaw, pitch, size}`（size 是画面半高，单位是模型单位）。镜头动作是镜头之间的关键帧，缓入缓出；size 按对数插值，推近拉远看起来匀速。

| 动作 | 表达什么 | 可以用在 |
|---|---|---|
| 全景定住，整块底座 | 这个地方是一个整体 | 开场；总结；换天色 |
| 推近到流程的一站 | "这就是这一步" | 值机柜台；一台机器；一间病房 |
| 沿一排东西横移 | 跟着一股流 | 排队；生产线；走廊 |
| 绕着模型转（yaw） | 同一个地方换一面看 | 绕到墙后面；从进站切到出站 |
| 压低俯角看进切面 | 截面里面 | 地道；地下室；管廊 |
| 一层一层往下 | 越来越深 | 矿井；地铁站；楼的各层 |
| 拉回全景 | 讲完了 | 回顾，动线还留着 |

- 人尺度的场景，近景用 size 7–10（人约占画面高度的 6–9 %）；全景要留边地放下整块底座。镜头永远不低于底座顶面。
- 俯角 30–45° 看进打开的房间；15–20° 看进竖直的切面。
- 默认一镜到底；只在两个定住的镜头之间才切。不用叠化。
- 标注跟着模型动；构图时给两侧的标注留地方。

## 7. 声音

- **小的有音高的乐器**：拇指琴、音乐盒、马林巴、玻璃钟、竖琴，底下一层很软的合成长音（pad）；五声或普通大小调。一步一个和弦；每步开始时一个往上走的短动机；底下轻轻一层马林巴的八分音型。
- **模型尺度的动作音**，全部由画面事件驱动：发动机和轮胎、轮轨的滚动声（过接缝的"咔哒"随车速变疏）、刹车放气、通用的两音开门提示（绝不用运营方的真实提示音）、闸机的提示音和门翼、传送带和扶梯的电机、屋顶抬起或落下时的小电机和木头"嗒"、每块标注的纸声、每批灯亮时的继电器"咔"。
- **按区域的环境声**：站外的空气和鸟、大厅里低低的人声、站台的空旷风声、地下的嗡声、夜里的虫鸣。
- **静默是工具**：亮灯前半秒近乎无声；继电器那一声"咔"是之后的第一个声音。
- 音乐压在动作音下面；用 `neo/audio/master.py` 母带到 −14 LUFS，用 `neo/audio/cues.py` 检查声音落在画面事件上。

## 8. 本风格特有的手法

- **掀盖子。** 屋顶、雨棚、上半截立面一起抬走；结尾再落回。*适合：* 医院病区；学校教室；数据中心；剧场后台。
- **跟着一个人。** 一个有颜色的小人走完整个流程，金色动线总比他先长出一步。*适合：* 病人从入院到出院；包裹穿过分拣中心；参观者穿过博物馆；选民走过投票站。
- **两股流，两种颜色。** 进是金色，出是青色，在不同的层交错。*适合：* 机场的到达和出发；厨房的洁污分流；商场的送货和顾客。
- **穿过切面。** 车或人群从一个切面进来、从另一个切面出去。*适合：* 盾构机；船闸里的驳船；传送带；桥下的游行。
- **钻进截面。** 镜头降到切面前，看地下有什么。*适合：* 地铁站厅；地下车库；综合管廊；基础。
- **亮灯。** 白天经过蓝调到夜里；灯一批批"啪"地亮。*适合：* 下班；夜市开张；比赛前的球场。
- **真实的周边。** 主体站在周围真实的楼群中间，楼群是 `neo/geo/buildings.py` 来的白色体块。*适合：* 新校园和它的邻居；规划中的塔楼在天际线里；一所学校和它的街区。

## 9. 这个媒介的坑

- **太满。** 每个房间都塞满人，就成了噪音。办法：座位坐三分之一到一半，人群之间留空，一条车道一辆车。
- **像素化回潮。** 抖动、像素滤镜、低多边形面片会让它像游戏。办法：倒角、平滑着色、2 倍超采样。
- **玩具感过头。** 饱和塑料、大倒角、高光。办法：倒角半径 ≤ .06，大部分表面粗糙度 ≥ .6，点缀色少。
- **两种比例打架。** 模型比例的小人旁边是地图比例的真实楼群。办法：中间隔一条街；真实周边只用纯白体块，不放小人、树、车。
- **透明玻璃太慢。** transmission 在 Windows 上要编译好几分钟。办法：半透明玻璃加环境反射（§2）。
- **正交下 AO 脏点。** GTAO 在空背景上画出脏斑，在玻璃边缘画出黑线。办法：模型外包盒裁剪，AO 那一遍把半透明网格藏起来（工具包两样都做了）。
- **屋顶挡镜头。** 正交视角下，抬起的屋顶会悬在近景上方。办法：全景时只抬一点，推近时升到画面外。
- **墙挡住动作。** 一整面高的正面墙挡住里面。办法：近处的立面切低（约半层），上面和屋顶一起抬走；或者绕到敞开的那一面。
- **白天开辉光。** 会把白模糊成一团。办法：只在夜里开，阈值高。
- **黄昏发棕。** 从浅灰混到夜蓝中间经过暖色就会发棕。办法：经过冷的蓝灰。
- **标注太短。** 一步里两块标注、每块要读三秒，五秒放不下。办法：让它们同时出现，或者把这一步拉长；用 `readcheck.mjs` 检查。
- **假装是真的。** 在真实地点的名字下面画一个编出来的内部，会误导人。办法：在页面和 `CREDITS` 里写清楚哪些是真实数据、哪些是示意（§10）。

## 10. 引擎（工具包使用说明）

工具包在 `demo/kit/`：普通的 ES 模块，three.js 通过 importmap 从库的 `/node_modules` 引入（见 `demo/index.html`）。`import { … } from './kit/index.js'` 就能拿到全部。

| 模块 | 内容 |
|---|---|
| `core.js` | 按种子的随机 `rng(seed)`（`range`、`int`、`pick`、`fork`）、缓动、`seg`、`env`、`Path`（折线：`length`、`at(d)`、`heading`）、`keyframes`、`stopAndGo`（匀减速进、匀加速出）、`resolveTime('@hero.sit+1.2', marks)` |
| `geom.js` | `bevelBox(w,h,d,r)`（自己写的倒角盒：每个面铺网格，顶点投到"内盒 + 半径"上）、`sphere`、`cylinder`（带缓存）、`Batch`（收集静态件，按材质合并）、`subtractBoxes`（盒减盒，挖地道、开洞用） |
| `materials.js` | `PALETTE`、`CLOTHES`、色彩比例；`mat`、`paint`、`metal`、`glass`；`earthMat`（按世界高度画地层）；`Glow`（会亮的材质分批，各有开灯时间） |
| `base.js` | `plinth`（带空的铭牌位）、`soil`（可挖空的土体）、`slab`（可开洞的楼板）、`wall`（可开门窗洞的墙）、`glassWall`（玻璃、竖梃、横梁）、`clipPlane`（沿 x 或 z 切开） |
| `parts.js` | `column`、`beam`、`railing`、`stairs`（返回走路的路径）、`escalator`（台阶会走；返回路径和速度）、`slidingDoor`、`gates`（一排闸机，门翼收回，由走过的人打开）、`bench`（返回座位）、`bin`、`sign`（只有象形图）、`canopy`、`tree`、`shrub`、`lamp`、`mast`、`board`（色块行组成的大屏）、`scanner`、`frameDetector` |
| `people.js` | `Crowd`（所有小人共用十几个实例化网格）、`makeLook`、行程（`walk`、`wait`、`until`、`sit`、`ride`、`climb`、`bagOff`/`bagOn`、`hide`、`mark`）、生成器 `seated`、`stream`、`offsetPath` |
| `vehicles.js` | `train`（车头、车厢、滑动车门、车窗会亮）、`schedule`（进站、开关门、出站；`doorAt(k)`）、`bus`、`car`（`kind: 'taxi'`）、`traffic`（循环车道） |
| `light.js` | 日光 / 蓝调 / 夜景三套 `PRESETS`，`LightRig`（`stateAt(keys, t)`、`apply`） |
| `post.js` | `Post`：MSAA → GTAO（外包盒、不算玻璃）→ 移轴（清晰带中心、半宽、过渡、半径、角度）→ 夜间辉光 → 输出 |
| `camera.js` | `CameraRig`（`'ortho'` 或 `'tele'`）、`S(target, yaw°, pitch°, size)`、`shots(keys)`，常用动作 `orbit`、`pan`、`descend`、`pushIn` |
| `explain.js` | `Overlay`（`badge`、`callout`、`layer`、`card`、`line`，`texts()` 给 `window.TEXTS`）、`RouteDots`（长出来的点线动线） |
| `context.js` | `context(parent, data, {scale, rot, offset, keep, glow})`：`neo/geo/buildings.py` 的真实轮廓和高度挤成白色体块 |
| `scene.js` | `buildMiniature(spec, {renderer})` → `world`，含 `update(t, night)`、`marks`、`refs`、`crowd`、`routes`、`glow`、`lightKeys` |

**场景描述。** 做一个新的微缩景观，主要就是写一份数据（示范片的是 `demo/station.js`）。单位约等于米；y 向上；地面顶是 `board.top`。任何写时间的地方都可以写数字或标记：`'@hero.sit+1.2'`（某人行程里的标记）、`'@A.open'`（车的 `arrive`、`stop`、`open`、`close`、`depart`、`gone`），或 `marks` 里的名字。

  groups: { roof: { lift: { dy: 30, keys: [['@lift', 0], ['@lift+2.5', 1]] } } },       // 写了 group: 'roof' 的件一起抬
  glow: { hall: { color: '#ffe0b0', on: '@lights' } },                                  // 夜里亮的批次
  build: [                                                                              // { type, …对应工具包函数的参数 }
    { type: 'slab', x: [-12, 12], z: [-6, 6], y: .15, t: .15 },
    { type: 'wall', a: [-12, -6], b: [12, -6], y: [0, 6], openings: [{ at: 12, w: 2 }] },
    { type: 'box', group: 'roof', box: { x: [-12, 12], y: [6, 6.5], z: [-6, 6] } },
    { type: 'bench', id: 'seats', at: [-4, .15, 2], rot: Math.PI, seats: 4, repeat: { n: 3, d: [3, 0, 0] } },
    { type: 'gates', id: 'gates', x0: -3, z: -3, y: .15, n: 4 },
    { type: 'tree', at: [-16, 0, 10], seed: 3 },

## 11. 变化空间

可以改的：地点（医院、机场、地铁站、商场、学校、工厂、港口）、怎么切（切哪几个面、哪几层、什么抬起来）、底座的形状、§3 范围内的点缀色、几个人、几股流、镜头路线、讲几步、只有白天或只有夜里、§7 范围内的乐器。

- **三种结构：** 从屋顶一路下到地下，一步一层；两股流交替讲（到达、出发），直到它们交汇；前后对比，模型一块块重新搭回底座上。
- **三种开场：** 俯视的平面图慢慢倾斜成模型；一个小人从切面里走出来；空的底座上，一层层叠起来。
- **三种结尾：** 盖子落下，模型被罩进玻璃罩；镜头升起，原来这个模型是长桌上很多模型中的一个；灯一间一间灭，只剩动线还亮着。
