# 微缩景观 Miniature — 风格说明

*English: [STYLE.md](STYLE.md)*

把一个真实的地方做成建筑师的剖切模型，放在一块薄展示底座上，用长焦去看：白色带倒角的构件，很少的点缀色，小人和车循环跑动，各层可以抬开露出里面，最后天黑、窗子一扇扇亮起来。我们的示范片《福田站，切开看》只是一个例子（[DEMO.zh-CN.md](DEMO.zh-CN.md)）；下面这些规则，才是让任何一部片子属于这个风格的东西。

需要：库自带的 core 工具（库 `node_modules` 里的 three.js r170 和它的 addons，声音用 numpy/scipy）。模型后面要放真实城市时，用 `neo/geo/buildings.py`（OpenStreetMap；Overture 要装 `duckdb`，见 [`neo/requirements-geo.txt`](../../neo/requirements-geo.txt)）。不用任何图片或模型文件。

## 1. 本质，以及它不是什么

- **桌上的一个模型。** 世界到薄底座为止。后面只有一片平的底色和底座的柔和投影；没有天空，没有地平线，底座以外没有地面。
- **切开给人看里面。** 一两个切面（正面，加一个侧面）露出各层。切面要露出材料：楼板的厚度，层与层之间沙色的土，带几道很淡的地层线。切口是直的，而且一直在原处。
- **长焦。** 正交（或接近正交）的视角：平行的边保持平行，不汇聚，模型读起来是小的。近景再加移轴模糊，上下虚、中间一条带是实的。
- **白模加很少的点缀色。** 几乎所有东西都是白、象牙白、浅灰；颜色只留给有意义的东西（§3）。
- **循环里的生活。** 人来回踱步，车进站、停、出站，各层分开又合上；什么都不模拟，一切都是时间的函数。
- 它不是等轴信息图（没有扁平图标，没有描边），不是像素或体素画（不像素化，不加抖动网点），不是玩具（没有亮晶晶的饱和塑料），不是写实的城市渲染（没有照片立面，没有天空），也不是折叠城市（没有铰链，没有平面海报，没有彩色天空）。

## 2. 材质与渲染

- **物理材质，安静的反射。** 哑光的石材和象牙白（粗糙度约 .75，加一层很淡的凹凸贴图做微表面），车身是带清漆的漆面，玻璃有透射、粗糙度低，栏杆和轨道是拉丝金属。低强度的室内环境光（PMREM）给出柔和的反射；看不到环境贴图本身。
- **每个构件都有倒角。** 方块一律是圆角方块，半径不超过 .045 个模型单位，也不超过最短边的六分之一；人头是球；树冠是一团小球。没有锐利的 CG 边，没有低多边形的棱面，没有像素台阶。
- **接触阴影让它变小。** 一盏主光配一张大的柔和阴影贴图；屏幕空间环境光遮蔽（GTAO）在 2 倍分辨率下计算，只限模型周围的一个包围盒；底座下面一块只接收阴影的地面。ACES 色调映射，曝光约 1.05，2 倍超采样加 MSAA。不加颗粒，不描边。
- **移轴是一道屏幕空间的后期**：可分离的高斯模糊，按离水平焦点带的距离加权；全景约 .3，近景 1。
- **夜晚靠自发光。** 路灯、标牌、车窗和背景城市的窗都是登记过的材质，自发光强度跟着光照状态走；每层有几盏暖色点光；辉光只在夜里开。
- **背景用真实数据，做成体量。** 主体周围的楼是真实的轮廓和高度，拉伸成白色体块：白天一层很淡的楼层带，夜里窗子分批亮。没有立面细节，楼群里不混放小人和车。

## 3. 色彩逻辑

- **中性的底。** 暖浅灰的背景，白和象牙白的模型。明度有顺序：底座最深（石板灰），切面居中（沙色的土、银灰的墙），模型最亮。
- **点缀色少而有意义**，加起来远不到画面的十分之一：交通线路公布的线路色（只用在线路色块和车身腰带上，绝不涂在建筑上），一类车一种颜色，地名一种颜色（红）。绿化是唯一面积大一点的自然色。
- **不画运营方标志或徽标。** 站名、线路号、线路色可以出现；标志不行。
- **天黑要经过蓝色。** 白天 → 蓝调时刻（冷的灰蓝）→ 深蓝黑；绝不经过棕色或灰色。室内暖光对着冷的月光。
- 不用纯黑，不用饱和的底色，底色不做渐变。

## 4. 字体与字幕

- **展签，不是字幕。** 说明卡放在下方一角：底色上的深色字，一个小的点缀色方块，中文用粗黑体（字重 600–700，1080p 下 30–80 px），下面一行小的拉丁字母，大写加字距或句子写法（15–18 px，字距 3–5 px）。日期或数字可以用更大的数字打头。
- **引线**把一列层名连到模型上的锚点，经过唯一的"世界 → 屏幕"函数，所以模型动的时候它们跟着走。
- **模型里的字**（站名、站台牌、线路色块）是模型的一部分：是招牌字，按招牌的大小。不用来写句子。
- 阅读时长：每张卡停留 ≥ max(1.8 秒, 中文字数 ÷ 4.5 + 1.5 秒, 拉丁字母数 ÷ 15 + 1.5 秒)；每张卡都通过 `window.TEXTS` 上报。
- 默认没有旁白。有配音时，字幕是一条展签式的条，底部居中，避开模型底座。

## 5. 运动质感

- 24 fps，逐帧；镜头、车和人每一帧都平滑地动。
- **车**以恒定减速度停到站位，再以恒定加速度离开（进站 `x = stop + D·(1−u)²`，出站 `stop + D·u²`）。车从切面进出（截面两端有裁剪平面），绝不凭空出现。
- **人**沿正弦路径来回踱步；转身时先转到面向镜头，步子的摆幅跟着速度。有几个站着不动。
- **层**用 2.5–3 秒的缓入缓出抬起，最上面一层先动，下一层晚 0.2–0.3 秒，落定时一声小小的"嗒"。跨两层的东西（楼梯、扶梯）随缝拉长。
- **灯一下子亮**，大约十分之一秒；背景的窗随后分批亮。
- 不动的：底座、切面、楼。不弹跳，不挤压，不晃。

## 6. 镜头语法

| 运动 | 表达什么 | 可以用在 |
|---|---|---|
| 从一个细节拉开到整块底座 | 尺度：这是整个地方的模型 | 揭示；第一眼；总结 |
| 长焦慢慢绕模型转（yaw） | 模型是一个可以绕着看的东西 | 时间流逝；光线变化；平静的停留 |
| 一层一层降下去 | 越来越深，一次一层 | 往下走的旅程；一个系统的层次；从上到下的流程 |
| 压低俯角看进抬开的缝 | 截面内部 | 层与层的关系；互相对照 |
| 沿站台横向慢移 | 跟着某一层的生活 | 到达；候车；一条生产线 |
| 锁住机位看整个模型 | 模型是一件完成的作品 | 读一张卡；对比；结尾 |

- 全景要露出底座完整的轮廓并留边；近景保留地面线（俯角 10–15°），一次一个主体。机位永远不低于底座顶面。
- 层名列和说明卡要避开模型；移动的是画面里的模型（镜头的目标点），不是字。
- 默认一个连续镜头；只在两次停留之间允许切。不用叠化。

## 7. 声音调色板

- **小的有音高的乐器**：拇指琴、音乐盒、马林巴、玻璃钟、竖琴，底下一层很软的合成长音；五声音阶或普通的大小调。用轻的"嗒"代替整套鼓。
- **拟音取真实的声源，按模型的分寸**：发动机，轮轨（接缝的"咔哒"随车速变慢），刹车放气，层移动时的小电机，落定时的木头"嗒"，亮灯时继电器的"咔"和灯管的嗡声，说明卡的纸声，镜头移动时一口很轻的风。到站提示音用通用的音程，绝不用运营方真实的提示音。
- **每层一种环境声**：上面是街上的空气和鸟，地下是低沉的厅堂嗡声，夜里是虫鸣和远处的城市。
- **把安静当工具**：层打开之前、灯亮之前，近乎无声（只剩一点空气）；安静之后的第一个声音就是那个事件本身。
- 音乐压在拟音下面；混音用 `neo/audio/master.py` 定到 −14 LUFS。

## 8. 这个媒介独有的动作

- **抬层。** 各层像千层蛋糕一样分开，每层带着自己那片切开的土，再合上。*适合的内容：* 一座医院的各层楼；一艘船的甲板；一座矿井的各个水平；数据中心的架空地板。
- **穿过切面。** 车或人群从一个切面进来，从另一个切面出去。*适合的内容：* 一台盾构机；船闸里的驳船；工厂里的传送带；桥下经过的游行。
- **一层一层。** 镜头穿过抬开的缝往下降，每一层停住配一张卡。*适合的内容：* 塔楼里坐一趟电梯；深水码头；博物馆的各层展厅；一座水厂。
- **亮灯。** 白天经过蓝调时刻到夜里；室内的灯一下子亮，后面真实的城市分批亮窗。*适合的内容：* 一个街区的傍晚；发布会之夜；开赛前的体育场；夜市开张。
- **真实的周边。** 主体站在它周围真实楼群的前面，楼群是白色体量。*适合的内容：* 一座新校园和它的邻居；一栋规划中的塔楼放进它的天际线；一所学校和它所在的片区。

## 9. 这个媒介的坑

- **太满。** 每层都挤满人和道具，就成了噪点。办法：每层几个人，人群之间留空，一条道一辆车。
- **像素化又回来了。** 抖动网点、像素滤镜、低多边形棱面会把它变成游戏。办法：倒角，平滑着色，2 倍超采样。
- **玩具感。** 饱和的塑料、很大的倒角、很高的光泽。办法：倒角 ≤ .045，大多数表面粗糙度 ≥ .6，点缀色要少。
- **两种比例打架。** 截面按人物比例（一个人约 1.2 个单位高，一层约 4 个单位）；按真实比例拉伸的背景楼群要大得多。办法：中间用一条街隔开，背景只画素白体量，不混放小人、树和车，每一边内部只用一种比例。
- **正交视角下的环境光遮蔽脏点。** GTAO 会在空的背景上写出脏斑。办法：给场景设一个包围盒，只在模型周围算。
- **跨过移动层的东西。** 层分开时楼梯和扶梯会撕开。办法：随缝拉长，或者只放在一层里面。
- **夜里辉光的光晕。** 白天开着辉光会把白模糊掉。办法：辉光只在夜里开，阈值要高。
- **浑浊的黄昏。** 从浅灰经过暖色过渡到夜蓝会发棕。办法：经过冷的灰蓝。

## 10. 引擎

- `demo/kit.js`：构件。`mat(color, roughness, metalness)`（带石材、木材微表面的物理材质），`glow(...)`（夜里会亮的材质，登记在 `NIGHT` 里），`box`（缓存的圆角方块），`label`（画布贴图上的招牌字），`tree`、`bench`、`railings`、`stairs`、`escalators`，`person` + `walk(w, t)`，`metroTrain`、`hsrTrain`、`cityBus`，`clipX`（在切面处裁掉车身），`earthMat`。
- `demo/model.js`：`buildCity(parent, data)` 把 `neo/geo/buildings.py` 的文件拉伸成白色体量（窗分六批）；`createModel(data)` 搭三层、各层的土和底座，并把静态构件按材质合并。
- `demo/main.js`：渲染器和后期链（带包围盒的 GTAO、夜间辉光、移轴着色器 `TILT`），`setCamera(t)`（由目标点、yaw、pitch、半高定的正交环绕），`drive(v, t)`（恒定减速和加速），`setScene(t)`（层、车、人、光），说明卡和引线（`drawCards`、`drawLayers`），以及声音事件（`window.EV`）。
- `demo/timeline.js` 管所有时间；`demo/mix.py` 读事件。

一个不在示范片里的最小起点，两层的渡轮码头：

```js
import { seg, eio } from '/core/lib.js';
import { box, person, walk } from './kit.js';
const deck = (y) => { const g = new THREE.Group(); g.position.y = y; scene.add(g); box(g, 20, .24, 8, 0, -.12, 0, '#d9d9cc'); return g; };
const lower = deck(0), upper = deck(4);
const crowd = [0, 1, 2, 3].map(i => person(upper, -6 + i * 3, 1.5, '#4e8198'));
window.render = t => { upper.position.y = 4 + 2 * eio(seg(t, 3, 6)); crowd.forEach(w => walk(w, t)); composer.render(); };
```

## 11. 变化空间

可以自由改的：地方和切法（切哪几个面，几层，每层放什么），底座的形状和颜色，§3 范围内的点缀色，背景楼群的范围，镜头路线，说明卡的内容和语言，只有白天或只有夜里，§7 范围内的乐器。

- **三种结构：** 从屋顶一路降到地下室；某一层的一天，从头班车到末班车；前后对比，切开的模型一块块重新搭起来。
- **三种开场：** 一张俯视平面图翘起来变成模型；一个人从切面里走出来；底座先是空的，然后各层一层层摞上去。
- **三种结尾：** 各层合上，玻璃罩落下盖住模型；镜头升起来，原来这个模型只是长桌上的许多个之一；灯一层层熄灭，最后只剩站名亮着。
