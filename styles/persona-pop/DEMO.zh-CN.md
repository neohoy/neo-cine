# 拟人 MV Persona Pop — 我们的示范片

这只是许多可能之一。不要照搬它的故事、起伏、镜头、道具和时间。

示范片：《一起跑通 Run It Through》（40 秒）· `persona-pop.mp4` · 源码在 [`demo/`](demo/) · 本文是 [DEMO.md](DEMO.md) 的中文版，以英文版为准。

**这是一支非官方同人片。** 两个角色是原创画的，名字取自两个真实的 AI 编程助手 Claude（Anthropic）和 Codex（OpenAI）：小克和扣扣。片中没有画任何一方的标志、吉祥物或界面；名字只出现在名牌和歌词里。本片不是两家公司制作、认可或审阅的，名字归各自的所有者。角色图用 Codex CLI 的生图工具生成（每条提示词都在 `demo/cast.json` 里）。

## 故事与结构

一句话：用户在群里丢下一句"做一支样片"；想得多的要先想，跑得快的要直接跑；两人分工，测试红了一片，画面在静默里冻住，副歌一到全部变绿，一起交出样片。

十段，每段 4 秒（120 BPM 的两小节），大多数段内再切一次：前奏（片名和群聊 → 对峙），四句主歌，四句副歌，尾声。用到的招牌动作：表面与内心（s1）、接管（s2）、翻牌墙（s3）、变红冻结变绿（s4–s5）、泳道和胶带（s6）、对撞（s7）、踩拍落地（s9）。

## 配乐结构

没有人声：伴奏和一条替歌词唱的主旋律，都由 `kit/tools/mix.py` 按 `mv.json` 和画面事件合成。

- 120 BPM，C 大调。前奏（2 小节，只有琶音，闷一点），主歌（8 小节：C–G–Am–F，半拍底鼓和军鼓，十六分方波琶音，锯齿波贝斯），副歌（8 小节：F–G–Em–Am，四拍底鼓，铺底，琶音里有八度跳），尾声（一记重音和一个长和弦）。
- 主歌最后一小节的军鼓滚奏被冻结切断；**19.52–19.84 秒是真静默**（−180 dB），然后切镜的"嗖"把气吸进第 20.0 秒的副歌重拍。
- 两处重音写在节拍网格上并和画面核对：第 20.0 秒的镲（冲击帧）、第 36.0 秒的底鼓（切到尾声），误差都是 0 毫秒。
- 主旋律：72 个音，一个字一个；小克是柔和的三角波，扣扣是窄方波，合唱两种都有，下方加三度。
- 混音：−14.0 LUFS，全片一个增益，真峰值 −2 dB。

## 配色与道具

- 角色比例：同一个角色的全身图按头的大小放成一个比例（`assets/chars/meta.json`）；两张欢呼是跳起来的，分别离地 0.17 和 0.13 个身高。
- 小克 `#D97757`（陶土橙），扣扣 `#148F65`（深薄荷绿），名牌黑底配 `#7CF5C4` 亮字；合唱名牌左右两色。
- 纸色底 `#F4EFE6`；整屏底色：藏青 `#1E2547`、薄荷 `#2FBF8F`、红 `#E5484D`、绿 `#2F9E62`、亮蓝 `#4C6FFF`、圆环淡蓝 `#E8ECFF`、桃色 `#F6DCCD`、终端底 `#151A33`。
- 角色：洋红底的 12 个全身姿势和 6 张胸部以上特写，加上两张透明底的 2×2 口型表（`demo/cast.json`），处理成 WebP 放在 `demo/assets/chars/`。
- 道具：群聊、思考卡片、终端、storyboard.json、测试列表、两条带锁的文件泳道、两张版本卡、渲染卡、胶片条、"样片进度"HUD。

## 构建说明

- `demo/mv.json`（时间、歌词表、配乐），`demo/cast.json`（角色、提示词、图片清单），`demo/scenes.js`（十段），`demo/index.html`（字体和场景样式），`demo/assets/chars/`（处理好的角色图和 `meta.json`，进 git），`demo/cast/raw/`（原图：18 张洋红底、2 张透明底口型表；不进 git）。
- `sh styles/persona-pop/demo/build.sh v004` 调 `kit/tools/make.sh`：逐字时间 → 去背景、统一比例、切口型表 → 字体 → 事件 → 混音 → 渲染（1080×1920，30 fps，1200 帧；整条构建在笔记本上用 3 个 worker 约 3 分钟）→ 合成 → 读字检查 → 海报。
- 审片：`node core/render/still.mjs styles/persona-pop/demo --range 0.6:40:1.6 --size 1080x1920 --out <目录>`，再用 `core/render/sheet.py` 拼起来。
- 读字检查：每一行歌词都通过；界面字、文件名、名牌、重复歌词的砸字和印章标了 `data-pass`。
- 这里踩过的坑：横跨整个画面的文本框（`left:0; right:0`）在镜头抖动或推近时会出画，readcheck 就判它"没有完整入画"：左右往里收；✗、✎、✳ 这几个符号三种字体都没有。
