# 拟人 MV Persona Pop — 风格说明

*来自库作者为两个 AI 编程助手做的一支同人 MV。本文是 [STYLE.md](STYLE.md) 的中文版，以英文版为准。*

> 一支竖屏音乐视频：两个二次元角色由图像模型画成静态抠图，一句一句把一件工作演出来。每句歌词配一个用代码画的界面梗（群聊、思考计时、终端、测试列表、合并冲突、渲染进度条）；歌词以卡拉 OK 大字的形式在画面上，跟着旋律逐字填色；整屏的底色、切镜和弹跳都卡在拍子上。
> 参考（只学语法）：中文短视频里的"AI 拟人"MV（把一个产品画成少女，表面的回答对照内心的独白）；偶像动画的片头（纯色底上的抠图姿势、速度线、冲击帧）；卡拉 OK 歌词视频。不照搬它们的角色、歌曲、版式和字体，片中也不点它们的名。

需要：库的核心工具（Node、ffmpeg 7+、`setup.sh deps` 装的无头浏览器和 `.venv`）；一个出角色图的工具（库里的 `core/image/gen_image.py`，它驱动已登录的 Codex CLI；也可以是用户自己的工具，用同样的提示词）；字体由工具包下载（OFL）。歌可有可无：用户自己的歌（带逐句时间），或者没有歌，这时工具包写一段芯片流行伴奏，再写一条旋律替歌词"唱"出来。其余都在 [`kit/`](kit/)，按 [`PRODUCTION.zh-CN.md`](PRODUCTION.zh-CN.md) 使用。

## 1. 本质，以及它不是什么

- **角色是会演的静图。** 每个姿势是一张单独的图（全身或胸部以上特写），透明底；表演就是选下一张图、再移动它，绝不扭曲脸。
- **每句都有梗，梗就是一块界面。** 歌词说发生了什么，画面上的一小块软件证明它真的发生了（计时在跳、终端在刷、测试在翻、冲突在合并）。
- **拍子看得见。** 身体踩拍压缩，镜头踩拍推一下，切镜落在半小节上，底色跟着句子换。
- **歌词是排版，不是字幕。** 顶部一行常驻的卡拉 OK，副歌钩子上再砸一组大字。

它不是对口型动画（嘴不会动），不是产品宣传片（不出现任何真实产品的界面：界面都是通用的、画出来的），也不是带字幕的口播。

## 2. 材质与渲染

- **角色：** 每支片按书面的角色设定生成一次，透明底（Codex 的生图工具直接给带 alpha 的 PNG；出不了透明底的工具用纯洋红 `#FF00FF` 底，洋红离肤色、发色，也离 AI 角色常穿的绿色、青色都远，由 `kit/tools/key.py` 抠掉）。每个角色先出一张定妆图；之后每个姿势都带着它作参考生成，提示词里反复写角色的轮廓特征。`key.py` 按头的大小给同一个角色的全身图定比例，不按包围盒，画小了的欢呼图上了画面不会变大（§5）。
- **口型表：** 要唱歌的特写，出一张 2×2 的表：同一张画，只改嘴和眼睛（闭嘴、"啊"、"哦"、眨眼），用那张特写作参考生成；`key.py` 切开，以第一格为准对齐。
- **界面：** HTML 卡片，中性的柔和投影（白底、36 像素圆角、标题栏），代码用等宽字体，每个名字一枚名牌。都是画出来的，不是截图：不用任何真实应用的外框、图标和标志。
- **从后到前的层次：** 底色和淡淡的网点 → 底层效果（放射线、圆环、代码雨、流线）→ 卡片和道具 → 角色 → 贴纸（颜文字气泡、闪光星、印章）→ 歌词层 → 进度 HUD → 白闪和冲击帧。
- 一切都是时间的纯函数（`kit/page/tween.js`），帧与帧之间不留状态。不加胶片颗粒：它会把纯色弄脏。

## 3. 色彩逻辑

- **一个角色一种颜色：** 用在她的名牌、她的卡拉 OK 填色、分屏里她那一半。两种颜色的色相和明度都要拉开，在纸色底和深色底上都要看得清。
- **暖纸色底**用于"平常"的镜头；**整屏饱和底色**用于情绪节点：红 = 失败，绿 = 成功，深藏青 = 专注或冲突，亮蓝 = 交付。换底色就是一次切镜，绝不淡入淡出。
- 合唱用墨色填字，名牌左右两色。
- 界面颜色只表达功能：红只给失败，绿只给通过，黄只给警告。投影用中性色，不用彩色发光。

## 4. 字体与字幕

- **三种字体**（OFL，`kit/tools/fonts.py` 按片子里的字切子集）：斜体展示字用于歌词、片名和印章（得意黑）；中文黑体用于界面小字（思源黑体）；等宽字体用于代码（JetBrains Mono）。不用系统字体。
- **常驻的卡拉 OK 行：** 左上，100–110 像素，每个字先是灰色带 12 像素白描边，唱到它那个音时填成演唱者的颜色（同时抬一下 0.07 秒再落回），每半句上面一枚名牌。整句从它那两小节开始一直在，到结束才走。
- **钩子砸字：** 选定的段落里，同一段词在下方那一带逐字砸下，150–190 像素（总宽不超过 960 像素），每个字从 2.4 倍落到 1 倍，比它的音早 25 毫秒落地，最后补一个"！"。砸字在的时候，常驻行缩成一半退到角上，仍然看得清：砸字是闪卡（`data-pass`），常驻行才是 readcheck 计时的那一行。
- **读字：** 片子需要观众读的字，都要在片子的尺寸下通过 `readcheck.mjs`；当纹理用的字（终端输出、文件名、计时器、名牌）标 `data-pass`。字绝不压在脸上；9:16 画面顶部 168 像素以内、底部约 1330 像素以下不放字。

## 5. 运动质感

- 30 fps，镜头、卡片、文字逐帧动。角色**只做整张图的变换：** 踩拍压缩（纵向 −3.5 %、横向 +2 %，0.28 秒回弹），跳（40–80 像素，0.28 秒），从上方落下正好踩在一拍上，滑入，小幅倾斜。什么都不弯。
- **换一个姿势就是一次表演：** 新图压扁着进来（1.12 × 0.86），0.13 秒回弹到位，然后保持到下一拍。
- **同一个角色一个比例。** 同一个角色的各个姿势，头一样大，身体中线在同一条线上（`assets/chars/meta.json`，`key.py` 写的）；跳起来的姿势按它的 `lift` 离地，不能被按回地面。换姿势时忽大忽小，看着是出错，不是表演。
- **特写要唱。** 唱歌的人的特写，自己唱的每个字张一次嘴（"啊""哦"交替，一句的最后一个字张 0.3 秒），停着的时候眨一两次眼（`sing`）。嘴是换图，绝不是把脸拉伸。
- 缓动：进场用 `back.out`，砸字和盖章用 `power4.in`，推镜回弹用 `power2.out`；只有旋转、滚动和代码雨用线性。
- 镜头在拍上或半小节上推一下（放大到 1.02–1.035 再回到 1）；同时叠加的推镜幅度加起来不超过 0.06，否则露出画框边。
- 每个镜头里角色都在呼吸或踩拍，只有**冻结**时例外：那时除了底色，什么都不动。

## 6. 镜头语法

| 镜头 | 表达什么 | 可以用在 |
|---|---|---|
| 硬切到一块新底色 | 状态变了 | 失败；成功；拿定主意 |
| 切到胸部以上的特写，慢慢推近 | 内心活动 | 犹豫；恍然大悟；坏笑 |
| 两个角色斜切分屏 | 两边、两份活 | 对峙；"你改你的，我改我的"；比较 |
| 漫画分格斜着甩进来 | 共同的反应 | 慌张；大笑；不敢相信 |
| 一个角色冲进来，把另一个撞出画面 | 接管 | "别想了，直接跑"；被打断 |
| 一格格踩拍翻出来的宫格 | 一下子出来很多结果 | 批量；相册；清单 |
| 冻结：一切停住，底色还在 | 转折前的那一刻 | 副歌前的静默；包袱 |

切镜落在半小节上（120 BPM 时是 2 秒）；一句里有转折时再切一次；一句话绝不是一个锁死的镜头。关键拍上的主体至少占画面高度的三分之一。允许的转场：硬切、带一帧白闪的切、两帧冲击帧。不用叠化，不用把整屏推走的划变。

## 7. 声音配置

- **用用户的歌：** 歌原样不动，音效垫在下面（低 6 dB，避开人声的字头）。
- **没有歌：** 芯片流行伴奏（方波十六分琶音、带高次谐波的锯齿波贝斯、副歌四拍底鼓、主歌半拍、一层轻微失谐的铺底），加上一条**替歌词唱的主旋律：** 从画面的 `syl` 事件来，一个字一个音，强拍落在和弦音上，句尾回到根音；一个角色一种音色（想得多的用柔和的三角波，跑得快的用窄方波），合唱时下方加三度。
- **音效就是界面自己的声音：** 切镜一声"嗖"，换姿势一声"啵"，打字一串键声，通过一声铃，失败一声低沉的蜂鸣，盖章是"咔"加一记闷响，落地一记闷响，对撞一声碎响。每个声音都来自一个画面事件（`window.EV`）；写在节拍网格上的重音要说明它属于哪个事件，并核对到 0 毫秒（`neo/audio/cues.py`）。
- **静默是工具：** 冻结时整段伴奏抽掉，留下真正的静默，由下一个重拍打破。混音到 −14 LUFS，全片一个增益（`neo/audio/master.py`）。

## 8. 招牌动作

- **表面与内心。** 角色在对话框里平静地回答，旁边她的内心计时在狂跳、草稿一行行冒出来。*适合的内容：* 客服机器人强装镇定；考前的学生；产品经理承诺上线日期。
- **思考计时器。** 计数器跑得太久，然后翻成绿色的"用时 6.0 秒"。*适合的内容：* 编译很慢；会开太长；想太多的模型。
- **变红、冻结、变绿。** 列表一行行变红，伴着抖动和故障条；整屏红底，两格慌张的漫画；半秒冻结的静默；然后副歌一到，每一行带着光圈翻成绿色。*适合的内容：* 上线失败；考砸了；输掉的比赛又赢回来。
- **对撞。** 两张卡片（两种意见）撞两次，合成一行，盖上一枚章。*适合的内容：* 合并代码；谈判；两份菜谱合成一份。
- **泳道和胶带。** 斜切分屏，各自的文件清单和锁，一条警戒胶带横穿而过。*适合的内容：* 团队分工；"别碰我的文件"；合租。
- **翻牌墙。** 用片子自己的角色图拼成一面宫格，一拍翻一张，带计数。*适合的内容：* 批处理；毕业纪念册；产品线。
- **踩拍落地。** 角色从上方落下，正好落在拍上，触地压扁。*适合的内容：* 结尾定格；团队亮相；神秘嘉宾。

## 9. 这种媒介的易错点

- **角色走样。** 没有定妆图、没有反复写轮廓特征，第二个姿势的发型或衣服就变了。办法：先出定妆图，每个姿势都带上它；动画之前把所有姿势并排看一遍。
- **洋红毛边。** 抠图不去溢色，头发外面会留一圈粉边。办法：工具能出透明底就用透明底，不能就用 `key.py`；每张抠图都放到深色底上看。
- **换姿势时忽大忽小。** 每张图都裁到同一个高度，举手或屈腿的姿势就会变大变小，跳起来的会落回地面。办法：`key.py` 按头定比例，并报出头到脚偏短的姿势；跳起来的写 `lift`；按真实比例把所有姿势并排看一遍。
- **不会动的特写。** 唱自己那句时特写一直闭着嘴，看着像贴纸。办法：口型表加 `sing`。
- **动脸。** 把整张图转好几度，或者说话时不等比缩放，看起来像橡皮。办法：换一张图。
- **歌词和砸字打架。** 砸字盖在常驻行上就读不清；只有砸字又过不了 readcheck。办法：砸字出现时，常驻行缩到角上。
- **真实产品的界面。** 画出真实应用的界面或标志，同人片就成了仿冒。办法：用通用卡片，名字只写在名牌上，片尾署名里写明非官方同人。
- **节奏一样平。** 40 秒每拍都切，人会麻木。办法：镜头长短跟着句子变，留一处冻结和一个停得久的特写。
- **字体里没有的符号。** ✗、✎ 这类符号常常两种字体都没有。办法：`fonts.py` 会列出来，换成 × 或文字。

## 10. 引擎

[`kit/`](kit/) 里的工具包能做完整一支片；[`PRODUCTION.zh-CN.md`](PRODUCTION.zh-CN.md) 是工作顺序。

- `kit/page/tween.js`：GSAP 写法的 `fromTo / to / set`，支持 stagger、repeat + yoyo、关键帧、颜色、SVG 属性和 `num()` 文字轨道，按时间纯函数计算。
- `kit/page/persona.js`：元件（`char`、`cu`、`rays`、`streaks`、`emo`、`sparkle`、`flash`、`impact`）和动作（`cut`、`swap`、`bob`、`hop`、`drop`、`kick`、`shake`、`impactAt`、`twinkle`、`emoPop`、`typeText`、`count`、`freeze`），每个动作都登记自己的画面事件；还有 `sing`（按歌词时间对口型；只是换图，不登记事件）。
- `kit/page/film.js`：挂载各段、歌词层（来自 `data/lyrics.json` 的常驻行和砸字）和进度 HUD；提供 `DUR`、`render`、`EV`、`TEXTS`、`READY`。`kit/page/base.css`：公共样式。
- `kit/tools/`：`cast.py`（通过 `gen_image.py` 出角色图）、`key.py`（去背景、同一个角色一个比例、切开并对齐多格表、写 `meta.json`）、`grid.py`（逐字时间：排到节拍网格上，或对齐人声的逐字时间）、`fonts.py`、`mix.py`（伴奏、主旋律、音效、卡点核对、母带）、`make.sh`（整片构建）。

一个示范片里没有的段落：第二拍弹出一条手机通知，并抖一下：

```js
{ id: "notif", start: 8, dur: 4,
  html: `<div class="card" id="n1" style="left:120px;top:700px;width:840px;height:160px" data-read="CI 失败：3 个用例">CI 失败：3 个用例</div>`,
  build(c) { c.pop("n1", 0.5); c.shake("n1", 0.5, 14); c.hit("buzz", 0.5); } }
```

## 11. 可变化的范围

每支片自己决定：两个（或三个）角色和她们的颜色、做的是什么活、哪几句砸字、哪些镜头用特写、冻结放在哪、§3 范围内的底色，以及 HUD 上写什么。

- **结构：** 从接到需求到交付的一天；一场较劲最后变成合唱；一首清单歌，每段主歌讲一个功能。
- **开头：** 一条通知把两个角色叫醒；带名牌的分屏对峙；先给最后的结果，再"八小时前"。
- **结尾：** 两人在最后一拍落地定格；HUD 走到 100 %，最后一声铃里画面暗下；一个把杯子递给另一个，冻结，片名。
