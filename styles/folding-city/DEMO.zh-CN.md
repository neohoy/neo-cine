# 折叠城市：我们的示范片

*本文是 [DEMO.md](DEMO.md) 的中文版，以英文版为准。*

这只是众多可能里的一个例子。不要照搬它的故事、结构、镜头、道具和时间。

示范片：《折叠深圳》（Shenzhen, Folded，40 秒）· `folding-city.mp4` · 源码在 [`demo/`](demo/)

## 故事与结构

深圳是沿着一条轴线向西长出来的：罗湖，然后福田，然后南山。片子把这条轴线做成首尾用铰链相连的三块地，一路走过去。每个区先是一张平面海报，再是一个有纵深的地方，再是一个会折叠的机关；下一个区是立在远端的一面墙，镜头翻上去，它就成了新的地面。最后三块地同时在画面里，折成一个 U：城市像盒子一样合上，标题在旁边。

没有旁白，没有角色。起伏靠节奏：三个区各十秒，音乐每个区加厚一层；两次换地块各两秒，重击之前留一口气；收尾六秒。

| 时间 | 段落 |
|---|---|
| 0–10 秒 | 罗湖 |
| 10–12 秒 | 福田滑入、立起 |
| 12–22 秒 | 福田 |
| 22–24 秒 | 南山滑入、立起 |
| 24–34 秒 | 南山 |
| 34–40 秒 | 连成一条、折成 U、标题 |

## 配乐结构

120 BPM，D 大调，一小节两秒，全部在 `demo/mix.py` 里合成。

- **罗湖（5 小节，Bm7–G–D–A–Bm7）**：最薄。琶音只落在弱位，低音，底鼓在一、三拍，边击。
- **福田（5 小节，G–A–F♯m7–Bm7–G）**：完整的十六分琶音，四拍底鼓，拍手，铃音旋律进来。
- **南山（5 小节，D–A–Bm7–G–A）**：最亮。每小节最后一拍加开镲，铃音旋律更高。
- **换地块（10–12 秒、22–24 秒）**：开头四分之一秒把总线压到几乎没有；铺底悬住，噪声往上扫，地块立稳的那一下（11.1 秒、23.1 秒）一记重击，然后一小段过渡接进下一个区。
- **收尾**：鼓撤掉，34 秒起一个 G 和弦悬着，上扫接收尾折叠的两记重击（36.2 秒、36.4 秒），最后是 D 和弦加五个上行的铃音，慢慢散掉。
- **动作音**来自 `window.EV`（导出成 `events.json`）：每次镜头运动一声呼啸，每次到位一声脆响或闷响，门扇和屏风折叠是棘轮加低频滚动，地块对接是滑动加咔哒，地块立起是吱呀加低频滚动。
- **环境声**：罗湖垫街市的低噪，福田垫风，南山垫海浪，收尾垫一层低频。
- `mix.py` 打印的各路电平（这支片子）：配乐 −12.0 dB，混响 −17.5 dB，动作音 −24.0 dB，环境 −27.1 dB（均方根）。成片响度 −14 LUFS。

## 落版

右边是折好的 U，左边是最粗字重的片名“折叠深圳”，一条短的黄色横线，一行拉开字距的 `SHENZHEN, FOLDED`。没有署名。

## 构建笔记

| 文件 | 画什么 / 做什么 |
|---|---|
| `demo/index.html` | 字体、三维舞台和二维叠字画布 |
| `demo/timeline.js` | 唯一的时间来源：各段时间、镜头状态、标量轨道、地块显示时段 |
| `demo/main.js` | 渲染器、铰链链条、镜头插值、光和天色、标签和标题、声音事件、`window.render` |
| `demo/kit.js` | 建筑积木：卡通材质、立面贴图、带窗格 UV 的几何体、楼、树、车、路面标线、街区填充 |
| `demo/luohu.js`、`futian.js`、`nanshan.js` | 每个文件一个区：它的配色和场景，以及管运动物体和铰链折叠的 `update(t, v)` |
| `demo/mix.py` | 配乐、动作音、环境声和总线 |
| `demo/tools/fonts.sh` | 下载三个字体文件 |
| `demo/build.sh` | 按顺序做完全部步骤 |

- 构建：`sh styles/folding-city/demo/build.sh`（导出事件 → 混音 → 24 帧、3 个进程渲染画面 → 按 −14 LUFS、BT.709 合成 → 文字停留检查 → 5.9 秒的封面和 14.2 秒的风格图）。已有成片时它不会覆盖：用 `OUT=<file.mp4>` 换个名字，或 `FORCE=1` 替换。
- 渲染时间：苹果芯片笔记本、3 个进程，960 帧大约三分半钟。
- 审片：镜头表里每个到达时刻出一张样帧，另加两次换地块的中间（10.7、22.7 秒）和收尾折叠的中间（35.6 秒）。
- 这支片子踩过的坑：
  - 罗湖立起来挡在福田前面，所有正面视角都被挡住：改成三块地互为兄弟节点，各自抄铰链坐标系的矩阵，在画面外的时刻单独隐藏（`timeline.js` 里的 `VIS`）。
  - 东门那排楼前面的低矮填充楼盖住了开场海报：换成草地和树。
  - 天色渐变到收尾时发浑：收尾的颜色单独用一条很短的轨道（`endMix`，0.25 秒）。
  - 腾讯的海报视角被近处的填充楼挡住：它前面那一条改成草地和棕榈。
  - 这支片子不是首尾相接的循环。
