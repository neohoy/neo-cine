# 极简地铁：风格说明

*本文是 [STYLE.md](STYLE.md) 的中文版，以英文版为准。*

> 一张真实的交通网，画成扁平、屏幕原生的线路图：平静的底色，水面和绿地是按真实轮廓、边缘柔和的平涂色块，粗而饱和的线、圆头，只走 0°、45°、90°，转角用同一个圆角半径；车站是在线上打出的孔；小方块列车按真实时刻表在线上滑行，每到一站都缓缓减速停稳。线不是印出来的：一只看不见的手把它从真实轨道里拉出来，线在手后面收紧成形。
> 参照（只学语法）：极简的交通解谜类游戏和扁平交通设计（平静的底色、留白、轻柔的微动效、小而干净的字）；八方向线网图。绝不照搬任何游戏或运营方的站点形状、乘客图标、界面（时钟表盘、计数器、线路色块栏）、配色、字体、音效和音乐，片中和文档里都不点名。

需要：核心工具；`neo/geo/routes.py`（真实轨道和车站）和 `neo/geo/osm.py`（水面、林地、公园），用同一个 `--origin`；列车按时刻表跑时用 `neo/geo/gtfs.py`。地图数据 © OpenStreetMap contributors，ODbL 1.0：先把条款告诉用户，片尾和 `CREDITS` 里署名，遵守 DIRECTOR.md §13。时刻表用运营方公开的 GTFS 或官方发车间隔，写明许可；片子不能声称比数据更精确。

## 1. 本质，以及它不是什么

- **平、静。** 一种底色铺满画面；水和绿地只是把底色往蓝或往绿推一点。没有纹理、阴影、发光、渐变和透视。
- **从真实的城市画出来。** 每条线都来自真实轨道，简化成八个方向，每个车站都留在真实位置附近；水面保持真实轮廓。
- **线是拉出来的。** 线头沿真实轨道往前走，手后面的线收紧成 45° 的台阶，收紧之后才打出站孔。
- **列车守时。** 每个方块都是一趟真实班次：起步、滑行、减速、停稳。画面上列车的多少就是运营的疏密。
- **留白里放字**：一个短的钟、一个计数、两行字幕，和线网分开。
- 不是瓷砖地铁图（没有瓷砖、镜头和材质），不是印刷的线路图（没有纸、没有光、没有三维镜头），不是游戏（没有玩家、乘客、分数和游戏界面），不是运营方的官方图（没有标志、线路圆标和专用字体）。

## 2. 材质与渲染

- **Canvas 2D 矢量，每一帧都由 `t` 算出。** 一个二维镜头（中心用米，放大倍数按对数插值）是地图唯一的变换。
- **线**：圆头、圆角连接，线宽用像素（整张网大约 7–8 像素，随放大倍数的平方根变粗）；转角是同一半径（米）的圆弧，只在很短的段上缩小。
- **八方向布局**（`tools/prep.py`）：每段站间连线取最近的八个方向之一，对相邻段的方向有一点"粘性"；用最小二乘解站位（每段想要"方向 × 真实长度"，每个站想待在真实位置）；重新取方向，反复几轮；最后做一次投影，让每段都严格八方向。会被压塌的段改成一个 45° 折弯，折在离真实轨道近的一侧。共用走廊的线按固定间距错开。
- **车站**：线上的一个孔（露出底色，半径约为线宽的四分之一）。**换乘站**：一块比线略宽的底色圆片，中间一粒墨色的钉。全网车站同一种标记，不用形状编码任何东西。
- **列车**：圆角方块，约 2.2 × 1.3 个线宽，顺着切线摆正，往行进方向的右边让一点，对开的车能错开，外面一圈底色的细边。
- **色块**：OpenStreetMap 的多边形，抽稀后把角柔化（Chaikin）；在这个比例尺下太细的溪流不画。
- **屏幕空间**：只有右边的文字栏；镜头推近时，文字栏后面升起一块平涂的底色面板，边上一根细线。

## 3. 色彩逻辑

- **一种底色**：白天是暖的浅灰，夜里是深的蓝灰；可以跟着当地当天真实的太阳走。水和绿地是底色的淡染。
- **饱和色只属于线**，用公开的线路颜色。没有车在跑的线往底色退大约四分之三：有颜色 = 正在运营。
- **列车 = 线色往墨色推**（白天更深，夜里更浅）。
- **墨**（字、换乘钉）跟着底色的明暗走，在深浅之间平滑过渡。
- 示例配色（本片）：底色 `#1b222c` / `#efebe3`，墨 `#ebe8e1` / `#262a31`，水 `#5d95bb` 三分之一，绿 `#7fa66a` 十分之一。

## 4. 字体与字幕

- **拉丁文用干净的几何无衬线**（Manrope，OFL），**中文用思源黑体**（OFL）。站名只用当地语言，15–17 像素，压到线的地方加一圈底色描边。
- **文字栏**：一个细体的数字钟（等宽数字）、星期、正在运行的列车数，以及字幕：中文一行在上、英文一行在下（1080p 下 ≥ 30 / 21 像素），不折行；字幕上方一道短线，结论用长一点的。
- 站名每个比例尺摆一次：在站点周围八个位置里挑不压线、不压别的字的那个。整张网的视图只标终点站。
- 默认无旁白。每条字幕停留 ≥ max(1.8 秒, 语音 + 0.6 秒)，并满足 `readcheck.mjs`；钟、计数和站名算"路过"的字。

## 5. 运动质感

- 24 fps，不抽帧；一切都缓动。
- **拉线**：线头沿真实轨道走，二次缓入缓出；线头后面约三个站距的范围里，线从真实走向松弛到八方向路径，带一点回弹；一段收紧之后，那里的站孔才弹开（短的 back 缓动）。
- **列车**在公开时刻之间按平滑的加减速曲线走，每站停稳；进场、退场按影片时间淡入淡出，约三分之一秒。
- **时间是主钟**：一条单调曲线把影片秒映射到当天时刻；可以加速、刹车，不能跳。钟快过大约每秒一刻钟时，单个列车淡出，只靠线的颜色说话。
- 收紧的线、车站、色块永远不动。什么都不晃、不"呼吸"。

## 6. 镜头语法

镜头状态 = 中心（米）+ 相对整张网的放大倍数。

| 运动 | 表达 | 可以用于 |
|---|---|---|
| 贴近、跟着拉线的手 | 正在成形；一条线的真实走向 | 开场；一条线从头画到尾 |
| 整张网，锁定 | 系统；读的时间 | 一个时刻；一个计数；一次对比 |
| 推进一个片区 | "就是这里、这几列车" | 一个换乘站；最忙的一分钟；一列车 |
| 拉回整张网 | 尺度；原来是一个系统 | 揭示；一段的收尾 |

- 整张网在最宽的视图里占画面宽度约一半，另一半留给文字栏；所有字离画面边缘 ≥ 40 像素。
- 转场就是镜头、拉线和底色本身。不硬切、不叠化、不对画面做擦除。

## 7. 声音调色板

- **软槌乐器**：带慢速马达颤音的颤音琴、毛毡槌木琴、带二三次谐波的正弦低音、一层气声长音。不用钢琴、弦乐和芯片音乐。
- 一部片一个调式；加速靠细分拍子，不靠改速度。
- **拟音就是这张图**：拉线时一道滤波噪声的"嘶"，每个站孔一下毛毡轻点（每条线一组音高），换乘站低一点，一条线收紧时一声轻"嗒"；列车靠站是一下很轻的毛毡点，声像跟着画面位置，越密越轻。
- **音乐可以跟着运营走**：线停了，声部就少一个；线开了，声部就回来。
- 环境是城市的空气声，很低；结论之前的静场只留空气。拟音干，颤音琴上一层偏暗的中等混响，−14 LUFS。

## 8. 原生动作

- **拉线。** 线沿真实轨道跑出去，在手后面收紧。*适合：* 一条线开通；一条路线从头走到尾；施工期间的绕行。
- **改线。** 已经收紧的一段被松开，沿另一条路重新拉。*适合：* 一条线截短；两条线贯通；临时接驳线。
- **线休息。** 最后一列车到站后线退进底色，第一列车开出时回来。*适合：* 夜间运营；罢工；周末停运。
- **底色就是钟。** 底色跟着真实的太阳走；一整天可以是一道 45° 扫过的颜色。*适合：* 一天的运营；一个季节；两天的对比。
- **计数。** 每个方块都是真实班次，所以它们的数目就是字幕可以引用的事实。*适合：* 早高峰；最忙的一分钟；安静的夜。
- **推到一站。** 近到能看清单个列车减速、停稳。*适合：* 一次换乘衔接；一个枢纽的一分钟。

## 9. 这种媒介的坑

- **锯齿**：一段一段地取方向会出台阶。给相邻段方向一点粘性，站位一起解。
- **城市不见了**：线路图做过头就认不出地方。站点留在真实位置附近，水面保持真实。
- **走廊里糊成一团**：平行的线按固定间距错开。
- **列车蹦出来或闪烁**：按影片时间淡入淡出，不按时刻表时间；钟很快时让线的颜色说话。
- **字压线**：搜位置、加描边，宁可少标几个站，也不要把字缩小。
- **假精确**：公开的时刻不是位置；要说明站间位置是推算的。
- **细溪读成界线**：城市尺度下不画（DIRECTOR.md §13）。

- [`demo/flat.js`](demo/flat.js)：`sky(m)`、`theme(ground)`、`restColour`、`trainColour`、`stroke`、`hole`、`knot`、`train`、`digits`。
- [`demo/main.js`](demo/main.js)：拉线（`peff`、`blendU`、`linePts`）、镜头（`camAt`）、列车（`trainAt`）、`placeLabels`、45° 的底色扫过（`ground`）、`window.TEXTS`、`window.EV`。

```js
// 和本片无关：一条橙色的线，从起伏的轨道被拉成一个 L
const geo = [...Array(40)].map((_, i) => [300 + i * 20, 600 + 40 * Math.sin(i / 4)]);
const oct = geo.map(([x], i) => i < 20 ? [x, 600] : [700, 600 - (x - 700)]);
const p = 30, b = u => Math.min(1, Math.max(0, (p - u) / 8));   // p = 已经拉出的点数
stroke(g, geo.slice(0, p).map((q, i) => [q[0] + (oct[i][0] - q[0]) * b(i), q[1] + (oct[i][1] - q[1]) * b(i)]), 8, '#e8822a');
```

## 11. 变化空间

由你决定：线网、线路、时段和日期、镜头路线、标哪些站、底色、§3 范围内的配色。

- **三种结构**：一条线从头拉到尾，一列车跟在后面；一天的高峰密度，计数就是故事；同一张网在改线前后。
- **三种开场**：空底色上一个站孔，线从孔里被拉出来；静止的整张网，一条线随第一列车开出而亮起；先只有钟，再有水，再有线。
- **三种结尾**：最后一列车减速进终点，线休息；镜头拉回，所有线一起在跑；静止的线网上，底色从夜扫到昼。
