# 游戏发布：我们的示范片

只是众多可能中的一个例子。不要照搬它的故事、结构、镜头、道具和时间。

示范片：《一趟跑商》*One Trade Run*，《归路：新旅途》的 Demo 宣传片（41.1 秒）· `game-launch.mp4` · 源码在 [`demo/`](demo/) · 英文版：[DEMO.md](DEMO.md)

**游戏和素材。** 《归路：新旅途》© 开发者青椒（个人开发者）；片中的实机录像、主视觉、立绘、Logo 和音乐都是游戏自己的，经开发者授权用于本示范片。来源是 TapTap 游戏页 https://www.taptap.cn/app/984135 上 9 分 24 秒的实机录像和图片。画面上的每个说法，连同页面原话或录像时间码，都列在 [`demo/FACTS.md`](demo/FACTS.md)；[`demo/CREDITS`](demo/CREDITS) 写明每样素材用在哪。示范片文件夹本身就是一个游戏发布工程（`demo/game.json` 是它的全部镜头表），用的是和用户的片子同一套工具包（[`PRODUCTION.zh-CN.md`](PRODUCTION.zh-CN.md)）。它把给这款游戏做的一支 HyperFrames 宣传片的 v002 版，改写成库的页面约定（同一个故事、同样的镜头和字幕牌），时间按库的读字规则调过。

## 故事和结构

三个方案里的 A，"一趟跑商"：一个真实数字贯穿全片。录像里交易所一轮卖货，货钞从 4351 涨到 14775（6:07.6–6:18.7）：这是高潮。之前是走到这一步的旅程，之后是另外两个玩法和伙伴，最后是去哪儿玩。（方案 B 角色群像，一个角色带一个玩法：录像里看不出谁做什么，会编，放弃；方案 C 用"遗失的日志"串起来：会冲淡玩家最买账的跑商。）

- **出发（0–3.4 秒）。** 主视觉（两位主角站在飞艇甲板上，飞艇在头顶），慢推向飞艇；第 0 帧起就有字幕牌「从一座城邦出发」。主视觉上印着的 Logo 留在画外。
- **跨城（3.4–6.9 秒）。** 飞艇飞过世界地图，推近 1.35 倍；「跨城跑商」。切点前一声风。
- **看行情（6.9–10.3 秒）。** 地区行情表，第二拍推进 1.55 倍；「看准行情」在左上。
- **低买高卖（10.3–20.1 秒）。** 交易所 1.6 倍速，第二拍推进 1.92 倍到货钞计数；「低买高卖」。计数一笔笔往上涨，17.2 秒落到 14775，「货钞 4351 → 14775」随一声"啵"擦开。落定那一刻起录像回到原速，14775 在字幕牌被读的时候一直在。
- **探索（20.1–23.6 秒）。** 节点地图，接「遗失的日志」事件的三条路；「探索秘境」。切点前一声风。
- **回合制（23.6–28.7 秒）。** 首领战的技能和命中，接自动战斗，游戏自己的横幅「自动战斗中」就是字幕；「深度策略回合制」跨两段。进战斗一声长风。
- **伙伴和收尾（28.7–38.6 秒）。** 六个角色按半拍擦入；「招揽伙伴」；铁板横幅滑入，和 Logo 一起落在强拍上（一记低音）；「Demo 试玩已上线」「TapTap 搜索「归路：新旅途」」「PC · 安卓 · iOS」一拍一行。
- **片尾卡（38.6–41.1 秒）。** 一整屏铁板从左滑入盖住收尾，落在切点上：NEO-Cine 和风格名。

用到的特有动作：在 UI 里读到那个真实数字、用游戏做的字幕牌、慢推进主视觉、一个镜头里的两个时刻（两次）、游戏自己的横幅当字幕、伙伴按半拍擦入、横幅和 Logo 一起落地。

## 声音

录像自己的原声，从 6:02.255 起（交易所的配乐，140 BPM；`beats.py` 在 43 秒里拟合出 140.03 BPM，拍点离第 0 秒 1.2 毫秒），里面带着游戏的界面点击声；淡入 0.15 秒，淡出 2.2 秒。八个合成音效：地图、探索、战斗三个切点前的风声（最后一个是长风）和横幅下的一声风，交易所推进的一声嗖，数字牌的"啵"，Logo 落地的低音冲击，片尾卡的一声闷响。没有旁白。卡点核对：10 个切点和落地对拟合出来的拍点网格，最大偏差 8.9 毫秒（30 fps 下不到半帧）。

## 配色和字幕牌

游戏交易所和对话框的 UI：枪灰铁板（#30343a → #1c1e22）、3 px 铜色外框（#6b3a20）、2 px 橙铜内描（#c46a34）、两颗银色铆钉、10 px 硬投影；字色 #f4efe6；Logo 的绿 #63dd8a 每块牌只给一个词；箭头用内描的铜色；要搜的字用更亮的铜色 #e3995f。`plate.py` 在交易所"总价"面板上读出的是同一族颜色（外框 #5c372c，强调色 #69dd83）。标题用得意黑斜体，斜笔画呼应 Logo；小字用 Noto Sans SC 600（HyperFrames 版用的是系统的冬青黑体，这里换成 OFL 字体）。

## 片尾卡

两张。游戏自己的收尾（带 Logo 的铁板横幅、Demo 试玩已上线、TapTap 搜索那一行、平台）是片子的内容。之后单独一整屏铁板，只署 **NEO-Cine** 和风格名「游戏发布」，用同一种材质，画面上不会出现暗底上的小元素。用户的片子只有前一种，没有后一种。

## 构建说明

```
demo/
  game.json        工程：录像（sources.play）、静图（每张怎么裁的写在 grab 里）、原声、字幕牌材质、8 个镜头
  build.sh         sh styles/game-launch/demo/build.sh v002（RENDER=remote 用渲染台式机；FOOTAGE=<路径> 把录像带进来）
  FACTS.md         画面上的每个说法，页面原话或录像时间码
  CREDITS          游戏素材属于谁、字体、声音、工具
  STORY.md         三个方案和选择
  assets/stills/   主视觉、Logo、六张立绘裁切（进 git，约 2 MB）
  assets/footage/  实机录像（不进 git：170 MB；build.sh 写明从哪来）
  assets/source/   裁立绘用的页面原图（不进 git；只有重裁时才要）
  frames/、data/、fonts/*.ttf、index.html、page/、out/    构建生成，不进 git
```

`assets/footage/play-4k.mp4` 不在时，`build.sh` 停下来并说明录像从哪来（9 分 24 秒那一条：`game.json` 里的时间码都对着它），然后以示范片为工程跑工具包的 `make.sh`：帧和静图 → 字体 → 页面 → 事件 → 拍子核对 → 混音（卡点、−14 LUFS）→ 30 fps 渲染 → 合成（BT.709，不加颗粒）→ readcheck → 海报（17.6 秒），再在缺的时候出风格帧（17.6 秒）和画廊副本。`clips.py` 在 Apple 芯片上约 20 秒切出 758 帧（约 210 MB）；本机渲 1234 帧约 25 秒。

- **检查（v001，在 Mac 上渲：那天渲染台式机拒绝 ssh 连接）：**readcheck 13 块字，0 BAD（最紧的是数字牌，2.64 秒对需要的 2.61 秒；招揽伙伴 2.44 对 2.39）；卡点 10 个切点和落地，最大偏差 8.9 毫秒；`mux.sh` −14.0 LUFS，LRA 9.6 LU，峰值 −1.7 dBFS；没有黑帧；母带软削波最深 5.6 dB（横幅和 Logo 落地）。原 SPEC 的 QA 时刻，换算到这一版的时间：第 0 帧是主视觉，没有印着的 Logo；5.0 秒飞艇可见；8.5 秒行情表读得清；12.0 秒货钞计数约 90 px 高；17.5 秒计数和字幕牌上都是 14775；22.5 秒日志三条路读得清；25.3 秒字幕牌不挡首领；30.8 秒六位立绘齐；34.3 秒 Logo 完整，在框里居中；38.0 秒三行字都在。
- **和 HyperFrames v002 对比**（17.4 秒之前同一时刻逐帧对，之后按对应时刻）：画面、取景、字幕牌一样。改了四处，都是为了库的读字规则：第一块字幕牌第 0 帧就在（原来 0.15 秒擦开）；看准行情在 0.12 秒出现，不等推进完；交易镜头长 3 拍，14775 落定后回到原速（1.6 倍速下 14775 撑不到字幕牌读完：录像 6:22.3 又买了东西，计数掉到 6308）；深度策略回合制在自动战斗那半段也留着；横幅晚一拍落地，让招揽伙伴读得完。收尾少停 1 拍，加了片尾卡。内容部分 38.6 秒（原片 37.7 秒），加片尾卡共 41.1 秒。HyperFrames 版用的是现成的音效文件，这里改成代码合成。
- **这支示范片的坑：**爽点之后货钞计数还会变（3.6 秒后又买了东西）；从落定那一帧起接一层原速，字幕牌说的就一直是真的。
