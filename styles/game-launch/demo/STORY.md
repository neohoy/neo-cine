# 故事：三个方案和选择

示范片《一趟跑商》的处理方案（PRODUCTION.md §3）。素材：TapTap 游戏页 app/984135 的实机录像（9 分 24 秒）、主视觉、Logo、截图和简介。

## 卖点和那个真实数字

- 商店页的说法：「深度策略回合制的二次元单机RPG」「跨城跑商、节点探索」「从最初的城邦出发，一路经商筹资、招揽伙伴、探索秘境」；开发者的话「游戏demo版已上线」。
- 录像里看得见的卖点：7:30 飞艇在世界地图上跨城；6:35.8 地区行情表；6:07.6 起交易所卖货；1:30.3 节点地图、1:16.4「遗失的日志」三条路；2:16.0 首领战、3:39.0「自动战斗中」；对话立绘（5:55、7:21、7:39.5）。
- 真实数字：交易所「持有货钞」6:07.6–6:09.0 是 4351，一轮卖货逐笔涨，6:18.667 落到 14775，停到 6:22.3（之后买入，变成 6308）。

## 方案 A：一趟跑商（采用）

- 手法：一个真实数字贯穿全片，货钞 4351 → 14775 那一刻是高潮。
- 前两秒：主视觉里两位主角站在飞艇甲板上，飞艇在头顶，第 0 帧就有铜牌字「从一座城邦出发」。
- 节拍：出发 → 飞艇跨城 → 看行情 → 卖货（货钞跳涨）→ 探索秘境 → 回合制战斗和自动战斗 → 伙伴阵容 → 铁板横幅、Logo 落地、Demo 已上线。
- 声音：游戏原声（交易所 BGM，140 BPM），换场一声风，Logo 落地一记低音。

## 方案 B：角色群像

- 手法：六位角色逐一登场，每人带出一种玩法。
- 缺点：录像里看不出哪个角色对应哪种玩法，容易编出原作没有的设定。

## 方案 C：一页旅行日志

- 手法：以探索里那本「遗失的日志」为线索，翻页进入各个场景。
- 缺点：偏剧情，玩家最买账的跑商会被冲淡。

## 选择

选 A：它的高潮是录像里真实发生的一个数字，最能说明"这是个跑商能赚翻的 RPG"；B 会编，C 冲淡卖点。
