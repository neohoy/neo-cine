# 方寸影像 Isle Film — 制作手册

*本文是 [PRODUCTION.md](PRODUCTION.md) 的中文版，以英文版为准。*

这份手册讲怎样从用户带来的东西，**一境用 NEO-Isle 造好的世界：一个 `fangcun/<nn>-<名>/` 文件夹，里面有它的 `world.js`**，只用库自己的东西做成片子：[`kit/`](kit/) 里的工具包，加上库的 `core/` 和 `neo/` 工具。风格的样子和规矩在 [`STYLE.zh-CN.md`](STYLE.zh-CN.md)；这里是干活的顺序。对这种风格，它代替 AGENTS.md 里的处理方案和分镜两步：`film.json` 里的镜头表就是处理方案，由用户确认。**下面三个确认点是风格的一部分，不能省**：镜头表、样张、渲染耗时（之后请用户完整看一遍、听一遍）。

所有命令都在库的根目录运行（技能模式下是 `$LIB`）。`<P>` 是这支片子的工程目录（AGENTS.md 的“Where things go”：克隆里是 `films/<name>/`，技能模式下是用户目录里的 `<name>/`；不放在 `styles/` 里，也不放进用户的 `fangcun/` 系列目录）。`K=styles/isle-film/kit`。Python 用库的 `.venv/bin/python`（`PY`）。

## 硬规矩

1. **这一境是用户的，原样不动。** `world.js` 只复制，不为片子改。不往世界里加东西（这一境没有的生灵、灯、天气、声音的来源）。片子需要这一境没有的东西时，告诉用户它应该进这一境（NEO-Isle），到此为止。
2. **引擎用工具包固定的副本**（`kit/isle-core/`，带影片模式的 NEO-Isle），或者这一境的系列自带的引擎（`_core/`，由 `new_project.py` 复制过来；它也要有影片模式）。渲染时页面从不去读用户的 NEO-Isle 目录。
3. **每一帧都是时间的函数**（STYLE.zh-CN.md 第 1 节）：不要往页面里加在帧之间留状态、读时钟或用 `Math.random` 的代码。
4. **第 0 帧是一个完整的画面**（背景里的容器）；只在进片尾卡时用黑。
5. **用户的片子不署 NEO-Cine**：工具包的片尾卡默认没有字，用户自己写了才有。

## 0. 简报

一次问清请求里没说的（AGENTS.md 的 Workflow）：

- **哪一境**：那一境的文件夹（`fangcun/02-snowfall-peak/`，或者他的系列放在哪里），或者 `world.js` 本身。有好几境就问哪一境；一境都没有，就先用 NEO-Isle 造一境。
- **时长**（默认 30～40 秒；10 秒的小样也可以），以及他在这一境里**最喜欢的那一刻**（一个生灵、一处地标、那件奇事、一个时辰）。
- **外观**：用这一境自己的（`meta.look`），或者换一个预设，或者把换外观当招牌动作（立方体 → 桌上的球）。只能用 NEO-Isle 的预设。
- **字**：片名卡（默认是系列和序号、境名，想要就加英文名），每个镜头一句短字幕或者不要，片尾卡或者不要。
- **声音**：默认代码合成；用他自己的音乐也可以（换掉配乐，环境底子保留）。

画面 1920 × 1080，24 帧。

## 1. 建工程

```sh
$PY $K/tools/new_project.py <P> --world path/to/fangcun/02-snowfall-peak [--name 文件名前缀]
node $K/tools/build.mjs <P>
```

`new_project.py` 复制 `world.js`（这一境用自己的引擎时，把系列的 `_core/` 复制成 `isle-core/`），写出 `film.json`（三个镜头的起稿，已经能渲：穿过玻璃进来、快进到夜里、拉远）、`CREDITS` 起稿和 `.gitignore`。`build.mjs` 写出 `isle.html`（影片模式下的引擎，three 用库自带的）、`index.html`（整片页面）和 `page/`，并打印镜头表。

## 2. 勘景

```sh
node $K/tools/survey.mjs <P>          # → <P>/out/survey.jpg 和 survey.json
```

第一次会顺带下载字体（约 30 MB）。它打印这一境的基本信息（名字、开场时辰、外观、默认镜头）、地标（最高点、湖、河的落差、给建筑整平的平台）和一张地面高度表，并存一张正午从正上方看、叠着每格 1 个单位的坐标网格的图。勘景图看不到的，去 `world.js` 里读：

- **生灵和它们的路线**：每个 `F.life(t => …)` 写着一只生灵在时间 `t` 时在哪里（绕圈、走八字、跑一段停一停）。片子里引擎的时间是 `clock + 片中秒数`（每个镜头再乘 `rate`），所以用 `clock` 把它们安排到镜头需要的地方；
- **地标和它的灯**：`HUT` 这类常量，以及点亮窗户的那段 `F.onLight`（从几点开始亮）；
- **奇事**：什么时候出现（`F.onLight` 里的 `L.night`、`L.hour`），往哪里动（`F.life`）；
- **这一境真有的声音**：风和雪，水（活水，还是只有冰），鸟（`kit.birds`；它不写是什么鸟：颜色深的用 `crow`，浅的用 `song`），别的没有。

用几行记下来（生灵、地标、奇事、时辰、声音底子）：镜头表就从这里写起。

## 3. 镜头表——确认点一

`film.json`：

| 字段 | 意思 |
|---|---|
| `name`、`world` | 输出前缀（`<name>-v001.mp4`）；世界文件（`world.js`） |
| `clock` | 片中第 0 秒时这一境自己的时间（决定生灵的位置；默认 0） |
| `looks` | 可选：`{ "名字": { "container", "backdrop", "glow" } }`，每个外观一页；默认只有一个，就是这一境自己的 |
| `title` | `kicker`（系列和序号）、`zh`、`en`、`at`（秒）、`dur`（秒） |
| `shots[]` | 镜头表；片长是各镜头 `dur` 之和加片尾卡 |
| `end` | `dur`、`fade`（片尾卡前淡到黑的秒数），可选的 `kicker`、`zh`、`en`（用户的片子默认不写） |
| `poster` | 海报取片中第几秒 |
| `sound` | `beds`（`wind`、`snow`、`water`：0～1；`birds`：`"crow"`、`"song"` 或 null），`music`（`key`、`bpm`、`level`、`drop`：配乐落在哪种事件上，默认 `wonder`），`chimes`（0～1） |
| `fadeIn`、`fps`、`three` | 可选：开头从黑淡入几秒（默认 0：第 0 帧就是画面），24，`"kit"` 表示用随附的 three |

| 镜头字段 | 意思 |
|---|---|
| `id`、`move` | 名字；它是哪种动作（`through`、`orbit`、`dive`、`timelapse`、`wait`、`pullback`、`swap`：STYLE.zh-CN.md 第 6 节） |
| `dur` | 秒 |
| `from`、`to` | 开头和结尾的镜头：`az`、`pol`（弧度）、`dist`（以容器为单位）、`target` `[x, y, z]`；没写的接着上一个关键帧或上一个镜头。不写 `from` = 镜头接着上一个镜头走，不切 |
| `keys` | 代替 from/to：`[{ "at": 秒, az, pol, dist, target }, …]`，一个长镜头经过几个位置 |
| `ease` | 整个运动的缓动：`inout`（默认）、`in`、`out`、`soft`、`linear` |
| `hour`、`hourEase` | 一个数（停住）、`[起, 止]`（在这个镜头里走完，按 `hourEase` 缓动）、或 `[[秒, 时辰], …]`；不写 = 上一个镜头最后的时辰 |
| `rate` | 这个镜头里这一境时钟的速度（默认 1；快进走的是时辰，不是时钟） |
| `in`、`inDur` | `cut`（默认）、`dissolve` 叠化或 `wipe`（一道斜的软边扫过去，换外观用），以及秒数 |
| `look` | 这个镜头用哪一页（`looks` 里的名字） |
| `focus`、`band`、`blur`、`tilt` | `"target"`（默认：清晰带落在镜头看着的地方）、一个点 `[x, y, z]`、一串 `[[秒, [x, y, z]], …]`，或者画面高度 0～1；清晰带半宽（0.2）、虚化强度（1）、`false` 关移轴 |
| `ride` | 0～1，代替自动的“跟着容器一起浮” |
| `wonder` | 镜头开始后几秒奇事出现：`wonder` 事件，配乐落在它上面 |
| `sub` | `at`（镜头开始后几秒）、`dur`、`zh`、`en` |

**按勘景的结果，照这个顺序写**：片子从哪里开始（通常是背景里的容器，`dist` 2～3），怎么进去（`through`）；值得给近景的那一个生灵；一天怎么走（在一处光会变的地标上 `timelapse` 一到三个小时）；在奇事出现的那个时辰 `wait`，取景在它会出现的地方；`pullback`。时辰朝一个方向走。

**时长。** 带片名卡的开场推近：到玻璃之前 4～6 秒。一个近景：4～6 秒。快进：5～7 秒走一到三个小时（整点会响钟：两到四声正好）。等奇事：6～8 秒，奇事在第 3～4 秒出现。拉远：5～7 秒，在结尾淡出开始前至少 1.2 秒落到 `dist` ≥ 1。片尾卡 3.5～4 秒。五个镜头就是 30～40 秒。10～12 秒的小样要整体压缩：`through` 4～5 秒，最多再加一个 2～3 秒的镜头，`pullback` 约 3 秒，淡出 1 秒，片尾卡不写字。

**靠边的近景。** `dist` 以容器为单位（立方体 dist 1 约 55 个单位），STYLE.zh-CN.md 第 6 节说的 0.08～0.15 只对地块中间、顺着地面看过去的注视点才在玻璃里。拍靠边的地标，把 `dist` 调到 0.05～0.07，或者从里侧看过去；近景关键帧的镜头在玻璃外、`through` 或 `pullback` 没穿过玻璃时，`build.mjs` 都会警告。

**换外观**（`swap`）只有在玻璃外（`dist` ≥ 1）才看得出来：在玻璃里，容器不在画面里。同一个 `dist`，圆形容器的取景比立方体近约 15%。

**读字时间。** 一块字要在画面上停 中日韩字 ÷ 4.5 + 其他字 ÷ 15 + 1.5 秒，而且要淡入到 60%、不再上浮才开始算：片名卡和片尾卡的 `dur` 里约有 1.2 秒耗在淡入淡出上，字幕约 0.6 秒。四个字的片名加七个字的小字，`dur` 要 ≥ 4.4 秒；六个字的字幕加一行短英文约 3.5 秒。`build.mjs` 按 `readcheck.mjs` 的口径算，列出不够的；`make.sh` 在渲染之前就跑 `readcheck`。

**奇事落在拍子上。** 配乐的一拍是 60 ÷ `bpm`（80 时是 0.75 秒）：把奇事的片中秒数（镜头开始 + `wonder`）放在整拍上，不然 `mix.py` 的卡点核对不过，并告诉你差多少。

```sh
node $K/tools/build.mjs <P>           # 镜头表：起止、动作、时辰、距离、叠化、奇事、整点
```

**把镜头表给用户看**：每个镜头的秒数、拍什么、时辰、画面上的字、奇事落在哪一秒。**等他同意。**

## 4. 看样——确认点二

```sh
sh $K/tools/preview.sh <P> auto                     # 每个镜头三个时刻，奇事前后各一张 → <P>/out/preview.jpg
sh $K/tools/preview.sh <P> 3,9.5,10.5,22.5,30       # 或者自己挑片中秒数
REMOTE=1 sh $K/tools/preview.sh <P> auto            # 在渲染台式机上截
```

一张静帧要先把这一境每个外观各建一次（几秒），之后近几年的 Mac 上每张不到一秒。逐张看：第 0 帧是完整的画面；片名读得清，镜头到玻璃前已经离开；镜头真的穿过了玻璃（构建时打印的 `glass` 事件：推进一次 `in`，拉远一次 `out`）；没有近景切进树或山里，也没有从玻璃壁看出去；生灵在画面里、在清晰带里；时辰看起来对（地标的灯、天色）；等奇事的镜头开头奇事还没出来，到它那一秒清清楚楚地在；亮地面上的字幕读得清；拉远在淡出前落到整只容器。在玻璃、叠化、奇事前后抽 0.25～0.5 秒一张的条（`node core/render/still.mjs <P> --range a:b:0.25 --out <P>/out/strip`，再用 `core/render/sheet.py` 拼）。

**把样张给用户看，等他确认样子。**

## 5. 声音

`mix.py`（`make.sh` 会跑）从画面事件做出全部声音：玻璃下面的环境底子（在外面是闷的，镜头穿过玻璃时打开，越近越清楚，鸟只在白天叫）、每个整点一声钟、穿过玻璃的声音、换外观时一声轻叩、奇事前的几乎安静和上扬的高处钟声，以及配乐（之前一层淡淡的长音和偶尔的钟片，之后带低音的完整和弦和一条按拍子走的钟片旋律，片尾卡下回到主和弦）。底子按这一境来选（第 2 步），调按情绪来选（D 明亮，A、E 更暖，F 更柔）。用户自己的音乐：把文件放进 `<P>`，复制一份 `mix.py` 到工程里，把配乐那一段换成他的音乐（`$PY <P>/mix.py <P>`），底子和钟点保留。

读它打印的东西：各路电平、卡点表（奇事和它的拍子差不超过半帧）、母带的软削波和限幅（好几个窗口被削 3 dB 以上，说明某个声音太冲）、最后的检查（−14 LUFS，`mux.sh` 一个增益就行）。

## 6. 成片——确认点三

渲染之前，**告诉用户要多久**：帧数 = 片长秒数 × 24；近几年的 Mac（Metal，3 个 worker）每秒约渲 5 帧（示范片：876 帧用了 165 秒），所以 36 秒的片子大约三分钟，再加一分钟编码和检查；在渲染台式机上（`RENDER=remote`，4 个 worker），上传工程、第一次还要传运行环境，多一两分钟。

```sh
sh $K/tools/make.sh <P> v001                    # → <P>/<name>-v001.mp4 和 <P>/poster-v001.jpg
RENDER=remote sh $K/tools/make.sh <P> v002      # 画面在渲染台式机上渲（neo/render/remote.sh）
```

`make.sh` 生成页面、切字体、跑 `readcheck`（放在渲染之前，查不过不会白占一个版本号）、导出事件、做声音、渲染、合成（`LEMO_COLOR=bt709`，颗粒 1）、出海报和接触表（`out/contact.jpg`，每秒一帧）。每次重做都是新版本（`v002`……）。然后检查：接触表，玻璃、叠化、奇事前后的条，`mux.sh` 打印的响度（约 −14 LUFS）。

**请用户完整看一遍、听一遍。** 声音只量过，没人听过：他看过听过之前，片子不算做完。

## 出了问题

- **页面一直不就绪**（等 `window.READY` 超时）：单独打开 `isle.html`（工具把库的根目录当网站根）看控制台；一境里的报错会以 `isle.html：…` 报出来。渲染台式机上报“Error creating WebGL context”，说明它的 GPU 此刻建不了 WebGL 上下文（有卡住的浏览器占着 GPU，或者驱动要重启）：在本机渲，并告诉用户。
- **这一境和它的网页长得不一样**：固定的引擎副本比造这一境时用的旧或新：`sh $K/tools/sync_isle.sh --check` 和用户的 NEO-Isle 比一比；永远不要改 `kit/isle-core/`。
- **`through` 没有 `glass` 事件**：最后一个关键帧还在容器外面（隔着透明的玻璃，远处的近景看起来像在里面）：把 `dist` 调小或 `pol` 调大，直到构建时列出它。
- **奇事的卡点核对不过**：挪 `wonder`，让镜头开始 + `wonder` 落在整拍上（60 ÷ `bpm`）。
- **readcheck 说某行不够**：少几个字、加长 `dur`，或者把 `at` 提前。
- **生灵不在镜头看的地方**：改 `clock`（所有生灵一起动）或镜头的 `target`；生灵的路线在它的 `F.life` 里。
- **字体缺字**：`fonts.py` 会说出是哪个字；Noto Serif SC 覆盖常用中文，Cormorant Garamond 只有拉丁字母（英文行里的中文会回退到宋体那一种）。
