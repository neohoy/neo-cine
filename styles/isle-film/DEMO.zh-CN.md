# 方寸影像 — 示范片：雪落寒山 Snowfall Peak

*本文是 [DEMO.md](DEMO.md) 的中文版，以英文版为准。*

> 这只是许多可能中的一个例子。不要照搬它的故事、结构、镜头、道具或时长。

**这一境：** 《雪落寒山》，NEO-Isle 的第二境，库作者本人做的：低云压着一座孤峰，一面冰湖，岩阶上一挂冰瀑，牦牛在雪原上绕圈走，一间挂着经幡的石屋；它的奇事是入夜后冻住的湖面下有发光的鱼在游。`demo/world.js` 就是 NEO-Isle 的 `examples/02-雪落寒山/world.js`，原样复制。为了片子没有往里加任何东西。

**这支片子：** 36.5 秒，24 帧，一个长长的下午落进夜里。在近几年的 Mac 上渲（那天渲染台式机的 WebGL 用不了）。

## 故事和结构

从很远到一个小生灵，穿过一天，到那一件不可能的事，再回到整只：到达 → 牦牛 → 黄昏里的石屋 → 冰面上的等待 → 夜里的整只容器。

## 镜头

| 秒 | 镜头 | 动作 | 时辰 | 发生了什么 |
|---|---|---|---|---|
| 0–12.5 | arrive | `through`（一个长镜头，三个关键帧） | 15.6 → 15.95 | 深空里一只小小的立方体慢慢靠近，片名卡立在左下；镜头碰到玻璃，立方体的棱扫出画面，声音打开（10.1 秒穿过玻璃），镜头低低地停在走过雪原的牦牛上方。“牦牛走过雪原 / Yaks cross the snow” |
| 12.5–19 | hut | `timelapse`（叠化 1.2 秒，慢慢绕） | 16.0 → 18.05 | 六秒走过两个小时，对着石屋和经幡：影子转过去，光从金色变成玫瑰色，窗亮起来；17 点、18 点响钟。“石屋点灯 / A window lights up” |
| 19–26 | wonder | `wait`（叠化 1.0 秒，推近 15%） | 18.05 → 19.1 | 黄昏里低低地对着冰湖，一只狐狸在冰上小跑；冰下升起一团暖光，鱼游到画面中间。配乐在 22.5 秒落下；0.4 秒后出“冰下有光 / Light under the ice” |
| 26–32.5 | whole | `pullback`（接着走，三个关键帧） | 19.1 → 19.9 | 从冰面退出来，再穿过玻璃（27.3 秒），直到整只立方体悬在黑暗里，里面有石屋的窗和湖里的光；31.3 秒开始淡出 |
| 32.5–36.5 | 片尾卡 | | | 黑底上：NEO-Cine / 方寸影像 / Isle Film |

`clock` 是 60：片中第 0 秒时这一境已经跑了一分钟，第一个近景时牦牛正走在环线靠镜头的一边，等待时鱼群正往湖的西半边游。

## 配乐结构

D 大调，80 BPM（一拍 0.75 秒）。从头一层很淡的 Dmaj9 长音，每三到五秒一颗钟片；整点钟在 17、18 点（白天，高）和 19 点（黄昏，低）。0.6 秒几乎安静，然后在奇事那一拍（22.5 秒 = 第 30 拍）一阵上扬落进五颗高处的钟，低音和 Bm 和弦进来，接着是 G；一条钟片旋律每拍走一个五声音阶的音。片尾卡回到 D，响到底。底子：风（玻璃外闷、里面开）、雪、白天几声寒鸦。没有水声：这一境的水是冻住的。

## 颜色和道具

全是这一境自己的：白和蓝灰的雪、深色的云杉、褐色的牦牛、石屋的暖窗、五色经幡、橘色的狐狸、鱼的琥珀色光。字是暖白，带一圈很淡的暗晕。

## 片尾卡

黑底：“NEO-Cine”（Cormorant Garamond 500），“方寸影像”（Noto Serif SC 300，字距很宽），“Isle Film”（斜体）。这一境、引擎、字体和工具的署名在 `demo/CREDITS`。

## 构建

```sh
sh styles/isle-film/demo/build.sh v002                   # 下一个没用过的版本号
RENDER=remote sh styles/isle-film/demo/build.sh v002     # 画面在渲染台式机上渲
```

`demo/film.json` 就是整个镜头表；`build.sh` 跑工具包的 `make.sh`（页面、字体、事件、声音、渲染、合成、读字检查、海报），输出写到风格目录，再按 `frame_sec` 出风格帧（26.8 秒：天黑了，冰下的光亮着，镜头还停在冰面上）。代码入口：`kit/page/plan.js`（镜头表 → 状态）、`kit/page/film.js`（页面）、`kit/tools/mix.py`（声音），以及 `kit/isle-core/fangcun.js` 里 NEO-Isle 的影片模式（`filmFrame`）。
