# 科技发布 — 我们的示范片

只是众多可能里的一个例子。不要照搬它的故事、起伏、镜头、道具或时间。

示范片：*On the Record*《记录在案》（35.4 秒）· `tech-launch.mp4` · 源码在 [`demo/`](demo/) · English: [DEMO.md](DEMO.md)

产品是建造观察局（BITBUILD，`news.bitbuild.cc`），一个讲 AI 和数字化工具怎样进入建筑、工程与施工行业的网站：公司档案、融资并购、深度文章。它是库作者本人的网站；片子里的每一块界面都是它的页面，2026-11-14 用 `kit/tools/freeze.mjs` 从线上冻结，画面上的每个事实连同出处页面和原文都列在 [`demo/FACTS.md`](demo/FACTS.md)。示范片文件夹本身就是一个科技发布工程（`demo/promo.json` 就是它的全部镜头列表），用的是和用户的片子同一套工具包（[`PRODUCTION.zh-CN.md`](PRODUCTION.zh-CN.md)）。它重讲了原技能做的 30 秒版式版，按库的读字规则重新排了时间。

## 故事与结构

难处、三个方案、收束。开场说读者的难处（噪音太多、事实太少：AI 发布到处都是，消息散在各个渠道）；每个产品镜头是一个功能怎样回应它，用一个组件和它那一页上的一个事实来证明；最后落品牌。

- **噪音（0–5.4 秒）。** "Too much noise, too few facts." 第 0 帧就在。八张真实的公司卡片从纵深飞来、散在画面里；说明里的槽位词在十六分音符上换过 公众号 / 官网 / 发布会 / 招股书 / 财报，停在"财报"。
- **一家一份档案（5.4–11.4 秒）。** 切点上，散落的卡片全部飞回公司库窗口里各自的格子，广联达最先；标题切片入场（从难处转到方案）；广联达抬起，画出角点、尺寸线和标注卡。
- **看数字（11.4–16.8 秒）。** 一件组件横贯画面：群核科技的那一行数字；推近 96.9%，数字卡数上去。
- **从发布到收入（16.8–22.8 秒）。** 分栏：左边标题，右边浮着两条文章摘要；Procore 那条抬起，划线沿着它原文里的"收入增长15.8%"走过去。
- **汇到一处（22.8–28.8 秒）。** 对照：一家国内公司的公众号文章和一家国际公司官网的发布，各标着渠道，一道括线收成"汇到一处"。
- **记录在案（28.8–32.4 秒）。** 两件组件收成建造观察局旁边的蓝色品牌方块；"On the record." 逐字打出；地址。
- **署名（32.4–35.4 秒）。** 画框淡出；空白纸面上只有 NEO-Cine 和风格名。

用到的招牌动作：散落再汇聚、槽位轮换、抬起加构造标记、推近计数、在原文上划线、括线收两个来源、窗口收成品牌方块、品牌一句话逐字打出。

## 配乐结构

工具包的合成配乐，D 大调，100 BPM（一拍 0.6 秒，每个镜头都是整拍）。开场 Dmaj9，铺底暗一点；产品镜头依次 Bm11 → Gmaj7 → Em9 → Asus2，第二个镜头起加很轻的底鼓和高帽；落版回到 Dmaj9，余音一直垫到署名卡。59 声合成音效落在画面事件上（散落的风声和纸声、九下槽位点击、飞回的风声、落定的低音和三下轻敲、每个切点前的渐强、抬起、角点、计数到位的轻敲、记号笔、括线的点击、方块的落定和铃声、逐字打出每字一下）。卡点核对：配乐的 14 个重音（5 个切点、4 个抬起和弦、3 个角点铃声、括线和方块各一声铃）对画面事件，最大偏差 0 毫秒。不配旁白：标题撑起全片。

## 色彩与道具

纸 `#f4f1ea`、墨 `#1a1916`、品牌蓝 `#002fa7`（站点自己的颜色：品牌方块、槽位下划线、划线、比例条、收尾的方块）。界面保持站点自己的颜色和字体（它的网页字体 Archivo、IBM Plex Mono 和它自己的宋体，以及字体栈里的系统中文黑体）。道具就是站点自己的组件：公司卡片（`.ccard`）、一家公司的数字行（`.dstat`）、文章摘要（`.drow`）、观察条目（`.erow`）。

## 片尾

两张卡。品牌的落版（第 6 镜：蓝色方块、建造观察局、地址、"On the record."）是片子内容的一部分，就像手账歌谣里歌曲自己的标题页：它说这支片子讲的是什么。之后另起一张空白卡，只署 **NEO-Cine** 和风格名"科技发布"；画框（品牌、标语、进度线）在它之前淡出。用户的片子有前一种，绝不会有后一种。

## 构建说明

```
demo/
  promo.json      工程本身：site（线上地址、四个页面和它们的组件）、film（品牌、7 个镜头）、name、poster
  build.sh        sh styles/tech-launch/demo/build.sh v002（RENDER=remote 在显卡台式机上渲）
  FACTS.md        画面上的每个事实、它在哪一页、页面上的原文
  CREDITS         站点、字体、声音、工具
  fonts/          OFL 许可文本（子集字体由 kit/tools/fonts.py 下载并切出，不进 git）
  site/、index.html、page/、out/    构建时生成，不进 git
```

`build.sh` 在 `site/` 不存在时先从线上冻结（约一分钟），然后用工具包的 `make.sh` 把示范片当工程跑：页面 → 字体 → 事件 → 音效和配乐 → 混音（卡点核对、−14 LUFS）→ 渲染 → 合成 → readcheck → 海报（20.4 秒），再在缺失时生成风格帧（20.4 秒）和画廊副本。线上站点会变：重新冻结后，渲染前先核对 `FACTS.md` 和样张（生成页面时会列出页面上找不到的数字）。本机（Apple 芯片，3 个 worker）渲 850 帧约 15 秒。

- **检查（v001）：** `readcheck` 29 块字，0 BAD（最紧的是窗口镜头的标注卡：要 2.41 秒，在画面上 2.52 秒）；卡点 14 个重音，最大偏差 0 毫秒；`mux.sh` −13.8 LUFS，真峰 −1.2 dB，LRA 5.4 LU；没有黑帧；母带的软削波有 2% 的窗口超过 3 dB（汇聚落定的那一声低音）。
- **和原技能的 30 秒版式版比：** 每个镜头的画风一致（窗口、单件推近、分栏划线、对照、方块落版）；为了让每句字都过库的读字规则，去掉了章节大字"Follow the money."，镜头各加了一两拍，中文标题和标注卡也改短了；站点本身也变了（27 家公司、300 条观察），所以主角换成了今天的。
- **这支示范片的坑：** 公司页上的 `.dstat` 是一个元素里装着四个数字，所以单件特写推近的是一整行；hero 版式让它从左边出画，推近时把 96.9% 推到中间。
