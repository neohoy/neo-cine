# 科技发布 — 风格说明

*来自库作者的 NEO 产品宣传片技能里的「科技公司式」主题，以及用它做的几支片子。English: [STYLE.md](STYLE.md)*

> 用产品自己的真实界面做的一支安静的发布片：页面原样冻结（它的 DOM、CSS、字体和图片），放在纸面上的产品窗口里拍，大号双语标题讲论点。真实组件从页面里克隆出来，像实物一样抬起、飞行、落定，每一件都是一个论点的证据，旁边一张小纸卡写着页面上的一个事实。
> 参考（只学语法）：发布会前放的产品短片和杂志的编辑版式（一行衬线大标题配一件东西，留白宽，只有一个强调色）；博物馆的展签（一张带线的卡，只说一个事实）。不照搬它们的版式、字体、画面和音乐，片子里也不提它们的名字。

需要：库的核心工具（Node、ffmpeg、`setup.sh deps` 装的无界面浏览器和 `.venv`）。产品：一个网址、站点的本地副本，或者界面截图。只有站点要用户登录时才要 Google Chrome 或 Microsoft Edge。字体由工具包下载（OFL）。其余都在 [`kit/`](kit/) 里：这个风格的片子用它做，一步一步照 [`PRODUCTION.zh-CN.md`](PRODUCTION.zh-CN.md)。

## 1. 本质，以及它不是什么

- **界面是真的。** 只用真实产品冻结下来的页面，或者用户自己给的界面截图：不重画、不做假界面、不编造页面上没有的数据。标注卡上的每个事实（数字、日期、名字）都能在冻结的页面上一字不差地找到。
- **标题是主角，界面是证据。** 一个镜头一个论点：一行大号英文衬线，一行具体的中文（不是翻译，是同一件事带上具体内容的说法）。能证明它的那个组件从页面里抬出来。
- **组件像实物一样动。** 卡片、一行数字、一条文章摘要，带着原样式、原文字从页面里克隆出来，在 3D 里动：沿 Z 轴抬起、飞回格子、推近、在原文上划线。
- **安静、信息密、准确。** 暖色纸面、黑墨、一个品牌色；慢的漂移都有方向；只有高潮前才完全停住。
- **每一帧只由时间决定**，第 0 帧就是完整画面（开场大标题完整在场：平台拿首帧当缩略图）。

不是录屏（没有活的网站在滚、没有到处晃的光标），不是假界面的解说片，不是霓虹"科技感"（没有光的渐变、粒子、玻璃拟态、深色科幻蓝），也不是动态文字片（字永远站在真实证据旁边）。

## 2. 材质与渲染

- **冻结的页面。** 浏览器打开每一页，点到要拍的状态，等它渲染完，把一切取下来：全部样式表（媒体查询按冻结视口求值，默认 1280×720，`vh`/`vw` 换成像素）、去掉脚本的 DOM、钉在原位的 `fixed` 和 `sticky` 元素、换成图片的 canvas、下载到旁边的字体和图片。站点自己的过渡和动画去掉（它们走浏览器时钟）。影片从不运行站点脚本：页面是一张能放大、能拆开的*活的截图*。
- **产品窗口**宽 1728 px，带一条细地址栏；只显示页面的焦点区域，按窗口宽度放大，左右各留 20 px（侧栏、站点页头不进画面）。页面缓慢下移，停在要讲的那一行。
- **浮起的组件**是真实元素的克隆，放在 CSS 3D 里：透视 2400 px，小角度（rotateY 约 −16°、rotateX 约 6°、一点 rotateZ），同时在场的几件前后错开 Z。透明的组件补上页面底色，不透出后面的东西。正文放大到约 21 px 才看得清：特写时组件约 600 px 宽。
- **三层柔和阴影**，随抬起高度加深、变散：东西有多高，由影子说，不由发光说。
- **Canvas 只画构造标记**：四个角点、一条尺寸线、一张纸色衬底的标注卡、一张数字卡、一道括线。不铺轴网、不画图纸线、不加粒子。
- **底**是纸色 `#f4f1ea` 加一点径向光（中间略亮、四周略沉），不用纯白，不用纯平底色。成片加一层很轻的颗粒压住色带。
- **能乱序渲。** 姿态是 t 的纯函数；文字入场是按 t 求值的补间（`kit/page/tween.js`）。不用随机数（散落的位置来自手写的落点表），不读时钟。影片自己的 id 和 class 带 `pp-` 前缀，不和站点撞名。

## 3. 色彩逻辑

- 纸、墨（`#1a1916`）、三种灰（次要文字、细线、眉题）。全片的颜色就这些。
- **品牌色只出现在品牌标志和由它长出来的东西上**：画框里的品牌方块、换页的品牌色擦除、落版时收成方块的窗口、槽位词的下划线、原文上的划线、计数下面的比例条。
- 界面保持它自己的颜色，在窗口里、在浮起的组件上都一样；影片从不给它改色。
- 深色界面放在纸面上对比很强：有浅色主题就用浅色主题冻结（`colorScheme`、`htmlAttrs`），没有就先截一张看效果。

## 4. 字体与字幕

- **英文：Instrument Serif**（OFL），窄体衬线，字距 −0.035 em，行高 0.92。开场 168 px，分栏 128 px，窗口和对照的标题行 104 px，单件特写的标题 80 px，章节大字 216 px，落版 196 px。一句话说一件事，最多两行。
- **中文：Noto Sans SC**，标题 700（开场 66 px、标题行 44 px、分栏 52 px），说明和标注卡副行 500（30 px，灰色）。按印出来的字切子集；不用系统字体，Mac 和 Windows 渲出来一样。中文写论点的具体说法（"27 家公司，各建一份档案。"）。
- **等宽：JetBrains Mono**，用在画框（品牌英文、标语、地址栏）、眉题、编号、网址；编号里的中文由 Noto Sans SC 接上。画框小字可以低于 28 px：它们是家具，不是要读的字。
- **站点自己的字体按站点原样。** 站点提供的网页字体原样保留；字体栈里的系统字体按名字声明（Mac 上是苹方，Windows 上是微软雅黑：就是站点在这两种系统上自己的样子）。它们的许可和界面本身一样，由用户负责。
- **标注卡**三行：编号（等宽 20 px，来源或编号）、事实（Noto Sans SC 700，30 px）、副行（500，22 px，灰）。事实是这一页上找得到的一件具体的事。
- **读字时间**照库的规则（汉字 ÷ 4.5 + 其余 ÷ 15 + 1.5 秒）：标题、说明、标注卡每一行、数字卡、标签都算；`readcheck.mjs` 检查成片页面，工具包在生成页面时就预警。计数从出现起就按最终值算，逐字打出从第一个字出现起就按整句算。字要少：产品镜头的中文标题 9–13 个字，卡上的事实 3–9 个字。
- **没有字幕条**：标题和标注卡就是片子的字。有旁白时交付它的 `.srt`（`core/render/srt.py`），除非用户要求，不往画面里烧字幕；字幕条会压住窗口。

## 5. 动作质感

- **入场：** `power3.out`，约 0.8 秒，模糊 14 → 0 px，逐行错开 0.1 秒。瀑布：英文逐词从下方甩上来（`power4.out`），后一个词在前一个落定前出发。切片：五条横条从不同偏移弹回（`expo.out`），一道品牌色细线划过。逐字打出：每个字十六分之一拍。
- **退场：** 文字向左退 140 px，`power3.in`，0.3–0.35 秒，落在切点上。
- **切点落在运动中。** 旧页在切点前 0.3 秒开始加速离开（`power4.in`），新页在切点那一帧以同样的速度、同一个方向进来，0.38 秒减速停稳（`power4.out`）；位移 200 px；绝不交叉淡化（两层叠着出一片灰），切点前也绝不完全停住。
- **落定**用五次方减速；飞行和抬起用三次方缓入缓出；主角落回一个已经在随页面离开的格子。
- **一个主方向：向左。** 文字向左退，新页从右边进，品牌色擦除从右往左扫。`up` 和穿越缩放留给有含义的换页。
- **停住只在高潮前**：抬起前 0.3–0.75 秒。不呼吸、不晃、不悬浮着来回飘：停留的组件朝一个方向慢慢漂（转向观众、往左漂），一直到离开。
- **卡在拍子上。** 关键时刻（切点、抬起、角点、标注卡、计数到位、方块落定）落在 0.6 秒的拍子上（100 BPM），快的连续动作（槽位、逐字、滚动）落在十六分音符上。镜头时长取整拍。
- **推近不拉回**：推近之后画面继续慢慢往里推 6%，一直推到切点，下一镜接着往深处走。

## 6. 镜头语法

画面是一张固定的页面加固定的画框（左上品牌、右上标语、底部一条进度线）；动的是组件和页面。下面是词汇，不是路线。

| 镜头类型 | 画面 | 可以用来 |
|---|---|---|
| 开场 | 左边大标题，右边纵深里的一组真实组件：一叠（`stack`）或散落（`scatter`） | 用户的难处，五个词说透 |
| 产品镜头 | 一个论点和它的证据，四种版式之一，配一个动作 | 一个方案，在界面上证明 |
| 章节大字 | 一行大字，不放界面，很慢地推近 | 论点之间的转折；换一口气 |
| 落版 | 品牌一句话、品牌方块加中文名、地址 | 收尾 |

| 版式 | 画面 | 动作 |
|---|---|---|
| `window` | 上标题、下产品窗口；连续几个窗口镜头窗口不动、里面换页 | lift、cascade、zoom、stream、mark |
| `split` | 左边大号双语标题，右边一到三件组件斜着浮起；宽的从右边出画 | lift、mark |
| `hero` | 一件组件占满画面宽度，标题缩成左下角一行 | zoom（配计数）、mark、lift |
| `compare` | 两件并排（宽的上下叠放），各带一行标签，一道括线收成一句结论 | 括线 |

| 动作 | 证明 |
|---|---|
| `lift`：主角沿 Z 轴抬起，窗口其余内容变淡，角点、尺寸线、标注卡 | "就是这一个" |
| `cascade`：主角周围的组件像波浪一样依次浮起落下，再由主角抬起 | "很多，都收拢在这里" |
| `zoom`：推近主角里的一个数字，数字卡从 0 数上去，下面一条比例条 | "一个关键数字" |
| `stream`：列表从顶上快速滚过、减速停在主角上，角上计数往上走 | "持续、大量、不断更新" |
| `mark`：抬起之后，品牌色划线沿着原文的那一句走过去 | "原文里就写着" |

换页：`left`（默认）、`up`（得出结论）、`zoom`（往深一层：两页都朝观众放大，模糊峰值 16–18 px）、`wipe`（打开一份档案：品牌色块在切点那一帧正好盖满窗口）、`cut`（冲击：新页略大地落下再收回）。相邻镜头的动作、标题入场、换页都不重复；重的手法（切片、擦除）一支片子一两次。

## 7. 声音

- **按镜头列表合成的配乐：** D 大调，100 BPM，温暖克制。失谐锯齿波铺底、带回声的滤波拨弦、正弦低频、FM 铃声；第一个产品镜头起一层很轻的底鼓和高帽。每个产品镜头一个和弦（Bm11 → Gmaj7 → Em9 → Asus2），切点那一拍低音加重，抬起落一个和弦，角点那一拍一声高铃；章节大字只留属和弦的长音；落版回到 Dmaj9 并留余音。
- **八种合成音效**，每个看得见的动作一声，峰值（点击和记号笔是起音）对在动作上：轻点击、木质轻敲、低沉落定、纸张、风声、渐强（每个切点前一拍推上去）、记号笔、轻铃。不用录音素材。
- **原声版配乐（可选）**：同一份乐谱，钢琴和弦乐，用库的采样器演奏；钢琴采样要署名（CC BY）。
- **旁白可选。** 默认不要：标题撑起全片。库的本地 TTS（Kokoro，中文音色 `zf_*`/`zm_*`）能离线用，但音色平淡，先请用户听一句。edge-tts 只在用户明确要用时才开：它是走非官方接口的微软 Edge 朗读服务。旁白讲因果，不念屏幕上的字；有旁白的段落配乐压低。
- 整片一个增益做到 −14 LUFS。

## 8. 招牌动作

- **散落，再汇聚。** 真实组件从纵深远处飞来，散在画面里；第一个产品镜头时全部飞回窗口里各自的格子，主角最先落定。*适合：* 信息散在很多地方；把东西收拢的产品。
- **一叠档案。** 三张卡片落成一叠、转向观众，最前一张飞进窗口。*适合：* 一个客户一份记录；档案；文件。
- **槽位轮换。** 说明里的一个词在十六分音符上换，越换越快，停在最后一个。*适合：* 同一种麻烦出现在很多渠道；很多格式；很多来源。
- **抬起加构造标记。** 主角抬起，画出角点和尺寸线，一张纸卡写一个事实。*适合：* 这个功能；这条记录；这个结果。
- **推近计数。** 推近一个数字，数字卡数上去，比例条填满。*适合：* 占比、增长率、总数。
- **在原文上划线。** 划线沿着页面上的那一句原文走过去。*适合：* 一句引文、一条条款、报告里的一个数字。
- **飞速滚过的列表。** 列表快速滚过、减速停在一条上，计数往上走。*适合：* 更新日志、资讯流、大量更新。
- **括线收两个来源。** 两件组件各带标签，一道括线收成一句。*适合：* 两个渠道汇到一处；前后对比；摘要和原文。
- **品牌色擦除**换页；**穿越缩放**进到更深的一页。
- **窗口收成品牌方块。** 片尾整个窗口（或最后一组浮起的组件）缩成品牌名旁边的方块，品牌一句话随后逐字打出。*适合：* 标志是简单几何形的品牌；"一切收进一处"。

新片可以考虑的候选（工具包里还没有，做的话挂在同一个时钟上）：整页放平、镜头飞过；组件环绕一个核心（成员必须真实）；光标点击带出下一镜；小功能一拍一个词；用结果数字开场。

## 9. 这种媒介的坑

- **假界面。** 重画的卡片、编出来的数字、"示意"截图：绝不。冻结页面上没有的事实不上卡（生成页面时会列出页面上找不到的数字；FACTS.md 每条写明在哪一页、原文怎么写）。
- **密码。** 要登录的站点，由用户在工具包弹出的浏览器窗口里自己登录；代理绝不往密码框里填任何东西，也不让用户把密码发过来。存下的登录状态只留在工程的 `out/`，不进 git，不送渲染机。
- **"做"而不是"看"。** 页面操作只切换、筛选、展开、搜索：不提交、不下单、不发消息、不改设置、不点同意。Cookie 横幅删掉，不点接受。
- **撞名。** 影片的 id 和 class 以 `pp-` 开头；站点自己用了 `pp-` 时生成页面会停下来。
- **冻结的不是想要的状态**：下拉还开着、筛选没生效。每一页都和参考截图对一遍。
- **30 秒里字太多。** 读字规则会让长标题不过；先删字，再考虑加长镜头。
- **划重点对不上。** 原文要在主角里一字不差地找到，而且是在冻结时找：改了就重新冻结。
- **同一页在窗口里出现两次。** 窗口里每页只出现一次；要拍两次就用另一个 id 再冻结一份（窗口外的版式可以共用一页）。
- **线上站点会变。** 重渲之前重新冻结并再核对一遍 FACTS.md；要固定一个版本，就留着 `site/`。
- **截图放大会糊。** 1 倍截图推近会糊：用 2 倍截图；页面把推近限制在截图的一个像素最多放大到屏幕上 3 个像素。
- **界面里的平台字体。** 中文用系统字体的站点，在 Mac 上是苹方，在 Windows 上是微软雅黑：一支片子在同一类机器上渲。

## 10. 引擎

[`kit/`](kit/) 里的工具包能从产品的网址或截图做出整支片子，[`PRODUCTION.zh-CN.md`](PRODUCTION.zh-CN.md) 是制作手册，写明了用户确认的三个点。细节看代码，这里不重复。

- 时间：`kit/theme.mjs`：镜头列表 → 时间线（`plan`）、镜头文字（`html`）、画面事件（`events`：切点、抬起、角点、计数，以及每个声音的时刻）、读字时间预估。
- 页面：`kit/page/template.html`（画框、窗口、字、CSS）、`kit/page/film.js`（窗口、页面、克隆、姿态、Canvas 标记、库的页面约定、给 readcheck 的 `TEXTS`）、`kit/page/tween.js`（文字入场，时间的纯函数）。
- 工具（`kit/tools/`）：`new_project.mjs`、`explore.mjs`、`login.mjs`、`freeze.mjs`、`freeze_images.mjs`、`build.mjs`、`fonts.py`、`voice.py`、`sfx_synth.mjs`、`score.mjs`、`score_acoustic.py`、`mix.py`、`preview.sh`、`make.sh`。浏览器公用代码在 `kit/lib.mjs`，模板在 `kit/templates/`。
- 示范片（[`demo/`](demo/)）本身就是一个用工具包做的工程：`demo/promo.json` 就是它的全部镜头列表。

## 11. 变化空间

每支片子自己定：产品和它的页面、难处和三四个方案、品牌色、片长（15 秒：开场加两个产品镜头；30–40 秒：四五个；45–60 秒：六到八个，需要时同一页冻结两份）、版式和动作（四个产品镜头至少两三种版式）、开场（一叠或散落，要不要槽位）、换页、落版（下沉或方块，模糊入场或逐字打出）、要不要旁白、合成配乐还是原声配乐，或者用户自己的音乐。

网站发布以外的用途：功能发布（一个镜头一个功能）、用截图做 App 或桌面软件、一块仪表盘的年度数字、文档或 API 产品（代码块和表格也是组件）、给团队看的内部工具介绍。

- **结构：** 难处 → 三个方案 → 收束；两页做前后对照；一个镜头一个数字，最后落在一句章节大字上。
- **开场：** 散落的组件加五个词的难处；一叠记录；先来一句章节大字，再进界面。
- **结尾：** 窗口收成品牌方块；窗口下沉，品牌一句话逐字打出；最后一句大字落在空白纸面上。
